# English translation rules

Source: the Traditional Chinese popular edition in `教材_暢銷版/`. Book title: **Why Doesn't AI Recommend You? — A Plain-Language Guide to GEO (Generative Engine Optimization)**.

1. **Translate only.** Do not add, remove, summarise, reorder, soften, strengthen or "improve" anything. Every sentence, list item, table row, heading, example and caveat in the source appears in the translation, in the same order. Keep the tone (friendly, plain, honest) and the metaphors exactly as written.
2. **Keep the Markdown structure identical**: same heading levels, bold, lists, tables, block quotes, code blocks, horizontal rules.
3. **Numbers**: keep every number unchanged. Convert Chinese units only in form: 「約 76.1 萬」→ "about 761,000"; 「3 成」→ "30%". Keep % and currency as written.
4. **Terminology**: use the English column of `教材_暢銷版/_術語表.md` for every glossary term, consistently. Keep product/platform names and crawler names exactly (ChatGPT, GPTBot, Google Search Console…).
5. **Evidence-strength phrases** must keep their exact strength, e.g. 「理論上可能，但還沒被證實」→ "possible in theory, but not yet proven"; 「有業內人士自己測過…（但沒有人獨立驗證過）」→ "someone in the industry tested this themselves… (but no one has independently verified it)".
6. **Hypothetical scenes** stay marked as hypothetical ("Imagine…", "Suppose…").
7. Chapter heading format: `# Chapter N — Title`. Recurring end-of-chapter boxes: 一句話記住 → "Remember in one sentence"; 你明天就能做的事 → "What you can do tomorrow"; 別再做了 → "Stop doing this"; 還不確定的事 → "What is still uncertain"; 這說明了什麼 → "What this shows"; 深入一點 → "A closer look"; 想像一下 → "Imagine".
8. Cross-references 「第 N 章」→ "Chapter N".
9. Natural, fluent international English (neither heavily British nor American slang). Short sentences, as in the source.
