# 2507.03169 Beyond SEO: A Transformer-Based Approach for Reinventing Web Content Optimisation

- 日期：2025-07
- 發表狀態：預印本（未註明；arXiv stat.ML，格式為學生團隊報告，含「各成員貢獻」聲明）
- 作者類型：學術（LSE 學生團隊）
- 一句話總結：用 LLM 生成的合成資料微調 BART-base，把旅遊網站內容改寫成「GEO 風格」，在 50 個查詢的小型模擬中 Llama-3.3-70B 位置調整字數可見度提升 30.96%，但樣本太小、無顯著性檢驗、標籤由 LLM 生成。

## 研究問題
小規模、領域專用（旅遊）的微調模型能否自動學會 GEO 改寫，並提升網頁在生成式引擎回答中的可見度？

## 研究設計
- 系統類型：模擬（固定上下文 LLM，5 個來源給 Llama 回答）
- 涉及的引擎和模型，以及測試日期：查詢生成用 Meta-Llama-3-8B-Instruct（溫度 0.9）；標籤改寫用 Llama-3.3-70B-Instruct-Turbo-Free（together.ai）；被微調模型為 BART-base；可見度評估用 Llama-3.3-70B（§3、§7.2）。無測試日期。
- 樣本：11 個旅遊子類別的合成查詢；每查詢取 Google Search API 前 5 個結果；清理後資料 1905 條（w, w'）；80/20 訓練/驗證切分，另有 50 個未見查詢（250 個網站）作測試集（§4.7、§5.1、§6.4）。可見度評估：50 個查詢，每查詢 5 個未優化網站，並隨機替換 1 個為優化版（§7.2）。
- 對照設計：(1) 5 個未優化來源 vs (2) 隨機一個被替換為優化版；文字品質層面對比 BART-base 基線（輸入長度設置不同：256 vs 384 tokens，§6.1）。
- 評估方式：文字相似度指標（ROUGE-L、BLEU、PPL、長度比）；可見度用絕對字數與位置調整字數（此處位置權重寫為線性衰減 1 − pos/|S|，與 GEO 論文的指數衰減不同，§7.2）。無人工驗證。
- 證據等級：E（固定上下文＋LLM 生成標籤＋n=50）。

## 主要發現（逐條列出，附數字和出處節號）
1. 測試集（250 條）最佳檢查點（epoch 7）：ROUGE-L 0.249 vs 基線 0.226；BLEU 0.200 vs 0.173；PPL 1.50 vs 1.71；長度比 1.00 vs 1.01（表 3）。
2. 可見度：絕對字數 +15.63%，位置調整字數 +30.96%（正規化且排除離群值；§1、§7.2、§8）。
3. 作者自述：樣本 n=50 不足以做統計顯著性、Llama 的 token 限制導致極端值、噪音資料（如網站與查詢不匹配）造成偏差（§7.2）。
4. 訓練標籤由三步管線生成：加引文 → 流暢度/簡化 → 加統計，並加入標題與分段結構（§3.3）。標籤本身的有效性未獨立驗證，只是依 GEO 論文的結論假設有效。

## 對應原理和管線階段
- 原理編號：[5, 6]。5：改寫時加入引文/統計/結構化段落；6：未評估被改寫內容是否忠實，且引文為「credible-sounding」，可能為捏造。
- 管線階段：生成/引用
- 新原理候選：無。

## 對實踐的含義
- 有實驗支持的做法：無可靠的實踐性結論（證據薄弱）。
- 作者建議但未經驗證的做法：用小型微調模型自動化 GEO 改寫；以強化學習直接優化可見度；結合 RAG 提升事實依據（§8 未來工作）。
- 被證明無效或有害的做法：無。

## 局限與效度威脅
- 作者自述（§7.2、§8）：n=50 太小；Llama 上下文限制；資料合成且有噪音、查詢與內容對不上；計算資源受限。
- 我方觀察：ROUGE/BLEU 僅衡量與 LLM 生成標籤的相似度，不是可見度；基線的輸入長度設置與提議模型不同，不完全是對照；未給信賴區間或顯著性；30.96% 由「正規化並排除離群值」後算出，細節不足；未與 GEO 論文的未微調 LLM 直接比較；優化內容含「credible-sounding」引文，真實性與保真度風險；標籤與評估使用同一 Llama 家族，可能有偏好回饋；位置權重公式與 GEO 不同，數字不可直接與 GEO 比較。
