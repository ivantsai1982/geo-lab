# 2510.16206 The Right to Be Remembered: Preserving Maximally Truthful Digital Memory in the Age of AI

- 日期：2025-10
- 發表狀態：預印本（未註明）
- 作者類型：業界為主（Insilico Medicine，含 Duke 與 Louisville 學者；作者聲明無利益衝突）
- 一句話總結：一篇立場/概念論文，提出「被記住的權利」（RTBR），主張 LLM 作為知識中介可能使數位足跡稀薄的個人與群體被抹除，並認為在基礎模型中 RTBR 應優先於個人的刪除權；全文無原創實驗數據。

## 研究問題
當 LLM 與 RAG 成為資訊主要入口時，缺乏數位存在、被過濾或被去排序的貢獻會被遺漏，應如何以規範和技術框架保障「最大程度真實」的數位記憶（摘要、引言）。

## 研究設計
- 系統類型：模擬或理論（規範性論述/文獻綜合，非實證）
- 涉及的引擎和模型，以及測試日期：無實驗；引用他人工作（MASK、真值方向探測、local intrinsic dimension 等）。
- 樣本：無。僅轉述一項外部數據：PubMed 496,665 篇文章（1966-2015）中 DOI 覆蓋率 40.48%，美英 46-57%，俄烏泰近 0-2%（「Why it matters」節，轉述自文獻 [8]，非本文測量）。
- 對照設計：無
- 評估方式：無
- 證據等級：E（純論述；非實證）

## 主要發現（逐條列出，附數字和出處節號）
以下均為作者論點，不是本文實驗結果：
1. 作者主張 LLM 把多種觀點壓縮成單一權威答案，且靠統計性放大主流敘事、弱化稀有或低數位可見度的來源（摘要、「Who is responsible」節）。無實驗證明。
2. 外部數據（轉述）：DOI 覆蓋率 40.48%，地區差異顯著（「Why it matters」節）。
3. 「連結腐爛」使可檢索內容減少；文中稱有研究表明中位 URL 約十年後不可訪問（引言，文獻 [6][7]；轉述，非本文測量）。
4. 責任歸屬論證：供應商（訓練資料選擇、過濾、RLHF、部署設計）為主要責任者，模型統計傾向與用戶提示詞也有影響（「Who is responsible」節）。
5. 規範主張：RTBR 應優先於 GDPR 第 17 條的個人抹除權；機器遺忘方法被描述為昂貴、不完美、可能損害整體效用（引文 [29]）（「RTBR vs Right to Erasure」節）。這是價值判斷，非實證結論。
6. 建議：分層溯源與歸屬（EKILA、C2PA 類）、不確定性校準與棄權機制、把真實性視為多層構念（準確性、溯源、誠實、包容性）（「Ensuring maximal truthfulness」節、討論節）。

## 對應原理和管線階段
- 原理編號：[1, 3, 10]。1：參數知識與檢索知識都有缺口；3：可被抓取/索引的內容決定可見；10：內容生態與可見度不均（無經濟數據）。
- 管線階段：抓取/索引、檢索（間接）、用戶行為/商業（間接）
- 新原理候選：「數位足跡稀薄者被系統性低表徵」（長尾與弱勢來源的公平性）；僅為作者論述，尚無實驗支持。
