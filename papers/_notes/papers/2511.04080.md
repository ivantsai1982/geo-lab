# 2511.04080 Caption Injection for Optimization in Generative Search Engine

- 日期：2025-11（arXiv v4 為 2026-06-29）
- 發表狀態：預印本（未註明）
- 作者類型：學術（中國科學技術大學；披露無利益衝突）
- 一句話總結：把圖片描述（caption）改寫後注入網頁文字，在多模態 RAG 模擬中使「主觀可見度」平均相對提升約 1.12%，但增幅很小、且單模態設定下反而為負。

## 研究問題
現有 G-SEO 方法（GEO、prompt 注入等）只改文字。當生成式引擎採用多模態 RAG 時，能否利用圖片語義提升內容來源在回答中的「主觀可見度」？（§1, §3.1）

## 研究設計
- 系統類型：模擬（固定上下文 LLM；為排除檢索干擾，把流程簡化為單輪回答生成，§4.1）
- 涉及的引擎和模型，以及測試日期：回答生成 GLM-4-9B；caption 由 Qwen-2.5-VL-7B 生成；所有基線與 Caption Injection 均用 GLM-4-9B 實現（§4.1）。無真實商業引擎，未註明測試日期。
- 樣本：MRAMG 基準 4,800 個 query-content 對，六個領域（Wit、Wiki、Web 共 1,850；Arxiv 200；Recipe 與 Manual 共 2,750），每樣本取三次獨立運行平均（§4.1）。
- 對照設計：與 Traditional SEO（關鍵詞）、Fluency Expression、Quotation Addition、Statistics Addition 四個純文字基線比較；單模態與多模態兩種設定；消融：structural vs refined caption、單次 vs 多次注入（§4.2, Table 3）。
- 評估方式：G-EVAL 2.0（沿用 GEO 論文，七維度 0–5 分：相關性、影響力、多樣性、獨特性、點擊跟隨概率、位置顯著性、內容量）；即 LLM 評判。caption 質量由多位領域專家抽樣檢查；最終可見度指標本身沒有人工驗證，作者自己說明它「不是人工標註的金標準」，只應作為方法間比較（§4.1）。
- 證據等級：E

## 主要發現（逐條列出，附數字和出處節號）
1. 多模態設定下 Caption Injection 平均相對提升 1.12%（±0.02%），比次佳的 Fluency Expression（0.71%）高 0.41%（Table 1, §4.2）。
2. 單模態設定下 Caption Injection 平均為 -1.01%（±0.06%），次於 Fluency Expression 的 -0.37%（Table 1）。所以摘要中「顯著優於」只在多模態設定成立；單模態下所有方法的平均值都是負的或接近零。
3. Traditional SEO（關鍵詞堆砌）在兩種設定下平均分別為 -2.30% 與 -0.66%；Statistics Addition 為 -4.13% 與 -2.12%（Table 1）。作者指出 Statistics Addition 的持續表現不佳與先前 GEO 研究「存在差異」（§4.2）。
4. MRAMG-Manual（平均文本長度 6,365.4 字元）上所有方法在兩種設定均為負（如單模態 Caption Injection -10.51%，多模態 -0.81%，Table 1）。作者推測是長文本稀釋關鍵信息（推測，未單獨驗證，§4.2）。
5. 有效優化率（相對提升為正的比例）：Caption Injection 由單模態到多模態上升 5.75%；Fluency Expression 的有效優化率低於 Quotation Addition 和 Traditional SEO，但提升幅度更高，作者據此稱「適應性」與「優化強度」是獨立維度（§4.2 Adaptability，數值只見於 Fig. 3）。
6. 貢獻主要來自「獨特性」維度：由單模態轉多模態時，Caption Injection 平均增量 2.13%，其中獨特性 3.50%；Fluency Expression 增量 1.07%，獨特性 1.58%（Table 2）。
7. 消融：refined caption 平均優於 structural caption（多模態 1.12% vs 0.71%；單模態 -1.01% vs -1.15%，Table 3）。多次注入在單模態把平均改善到 -0.63%，但在多模態降到 0.01%（Table 3）。原因為作者推測。

## 對應原理和管線階段
- 原理編號：[5, 4, 9]。5：附帶結構化、可抽取的補充語義（圖片描述）；4：內容進入上下文後被 LLM 吸收的程度（此處以 LLM 評判分數代理）；9：屬內容改寫類優化，並顯示各策略效果與領域相關。
- 管線階段：生成/引用（以 LLM 評判可見度為代理）；也涉及內容側的多模態表徵。
- 新原理候選：多模態內容（圖片轉文字描述）如何影響被引用；但本文只在模擬中做，證據弱，不足以獨立成條。

## 對實踐的含義
- 有實驗支持的做法：僅在模擬與 LLM 評判下，給文字補充與圖片對應的、與上下文對齊的描述，在多模態 RAG 下有小幅（約 1%）正向效果（Table 1, 3）。
- 作者建議但未經驗證的做法：把方法用到真實 GSE；對 VLM 直接讀圖的引擎是否有效未測試（Limitations）。
- 被證明無效或有害的做法：Traditional SEO 關鍵詞與 Statistics Addition 在此設定下平均為負（Table 1）；長文本（Manual）上任何優化都為負。

## 局限與效度威脅
- 作者自述：增幅僅約 1.1%；沒有與能直接處理圖像的 VLM 比較；不清楚是否轉化為真實用戶感知（Limitations）。
- 未涉及真實檢索；只用單一生成模型 GLM-4-9B（§4.1）；指標為 LLM 評判，且相對提升公式分母加 1（式 4），對小分值敏感。
- 提升量級（±0.02% 誤差）與 LLM 評判噪音相比是否有實質意義，論文未做人工驗證。
- 「顯著」由作者聲稱做了統計檢驗，具體檢驗方法在正文中未給出。

## 與其他研究的關係
- 支持哪些研究的結論：延續 GEO（Aggarwal et al., KDD 2024）的評價框架。
- 與哪些研究的結論矛盾：Statistics Addition 表現與原 GEO 論文結論不一致（§4.2 作者自述）。

## 值得到從業者社群（Reddit）驗證的問題
- 在真實 AI 搜索（如 Google AI Overviews、Perplexity）中，替圖片寫更豐富的 alt 文字或圖說，是否影響被引用？
- 長頁面（手冊類）是否真的更難被引用？
