# 2601.00869 Cultural Encoding in Large Language Models: The Existence Gap in AI-Mediated Brand Discovery

- 日期：2025-12
- 發表狀態：預印本（未註明；arXiv cs.AI）
- 作者類型：GEO 或 AI 可見度服務商（OmniEdge/Zhizibianjie AI 諮詢公司；案例品牌 Zhizibianjie 即作者所屬公司的平台，論文聲明「無商業關係」，但作者單位與案例品牌同名，利益衝突需高度留意）
- 一句話總結：用 6 個 LLM 在純英文查詢下比較品牌提及率，發現中國 LLM（88.9%）遠高於國際 LLM（58.3%），並據此提出「存在缺口 / 數據護城河」概念框架；但設計為橫斷面、無法歸因於訓練資料，且作者為受益方。

## 研究問題
不同地域訓練語料的 LLM 是否對品牌給出系統性不同的推薦（Cultural Encoding）？品牌若不在訓練語料中是否等於「不存在」（Existence Gap）？（§1、§3）

## 研究設計
- 系統類型：商業引擎（經官方 API 呼叫，含 GPT-4o Search Preview 等帶搜索型號；論文未區分是否啟用檢索，卻把差異全歸因於「訓練資料地理」）
- 涉及的引擎和模型，以及測試日期：GPT-4o Search Preview、Claude Sonnet 4.5、Gemini Pro Latest（國際）；Qwen3 Max Preview、DeepSeek V3.2 Exp、Doubao 1.5 Thinking Pro（中國）；「2026 年 11–12 月」經 API 存取（§4.2；論文封面日期寫 December 2026，但 arXiv 標記 2025-12，日期自相矛盾）
- 樣本：30 個品牌（10 西方/10 中國/10 全球；協作/專案管理/生產力軟體）、10 種查詢類型；原 2,800 個查詢-LLM 對，剔除 891 對含中文字符者後剩 1,909 對純英文（國際 955、中國 954）（§4.3–4.4）
- 對照設計：準實驗，國際 vs 中國 LLM 組，相同英文查詢；單次收集，未見重複次數
- 評估方式：二值提及（2 名編碼員一致率 98.2%，κ=0.96）；情感三點量表（κ=0.91）；卡方、t 檢驗、邏輯回歸（§4.5–4.6）
- 證據等級：E（商業引擎 API 單次橫斷面，無重複/多日期設計，無法隔離訓練與檢索；因果論述屬理論推演）

## 主要發現（逐條列出，附數字和出處節號）
1. 提及率：中國 LLM 88.9%（848/954）vs 國際 LLM 58.3%（557/955），差 +30.6pp，χ²(1)=226.60，φ=0.34（§5.1 表 1、§5.2）。
2. 按品牌來源（表 2）：中國品牌 國際 31.2% vs 中國 96.8%（+65.6pp）；西方品牌 72.1% vs 81.3%（+9.2pp）；全球/混合 71.6% vs 88.6%（+17.0pp）。即差距主要來自中國品牌。
3. 按查詢類型（表 3）：Positional 45.2% vs 92.1%（+46.9pp）；Recommendation 51.3% vs 90.4%；Comparative 68.7% vs 87.2%；Informational 73.1% vs 85.6%（+12.5pp）（§5.1、H3）。
4. 情感（有提及者 N=1,405）：中國 LLM +0.71 vs 國際 +0.42，t(1403)=−11.76，d=0.53（表 4）。
5. 案例 Zhizibianjie：國際 LLM 0/32（0%），中國 LLM 21/32（65.6%），χ²=21.33，φ=0.58（表 5）。
6. 作者建議的 18 個月路線圖預期「提及率提升 40%+」（§6.2）——這是預測，論文未驗證。

## 對應原理和管線階段
- 原理編號：[1, 3, 10]。1：參數知識 vs 檢索知識（但論文未將二者分離）；3：第三方/語料來源對可見度的作用。
- 管線階段：觸發、生成/引用（品牌是否被提及）
- 新原理候選：「跨引擎/跨地域的基線可見度差異」——同一品牌在不同引擎族群（地域）中的可見度截然不同，測量需按引擎分層。這與原理 7 相關但未被單獨列出。

## 對實踐的含義
- 有實驗支持的做法：無。論文沒有做任何干預實驗。
- 作者建議但未經驗證的做法：雙語內容、技術文件與 API 文檔、社群（GitHub/Stack Overflow）與案例研究、18 個月內三階段（§6.2）；「Data Moat 深度 Db=Σwi·Qi」為未估計的公式。

## 局限與效度威脅
- 作者自述：僅協作工具品類；6 個模型；橫斷面無法確立因果；Zhizibianjie 為單一案例（§6.3）。
- 我方讀出的威脅：(a) 作者為案例品牌所屬公司，選案例的動機並非中立；(b) 「地域 vs 語言」的識別：剔除含中文字符的查詢，恰好剔除了大量中文品牌（DingTalk、Feishu 等）查詢（§4.4），使中國品牌樣本被系統性篩選，而國際 LLM 對中國品牌的低提及可能反映的是檢索/品牌知名度而非「訓練語料」；(c) 「中國 LLM 提及率高」也可能反映回答風格（更愛列多個品牌）或不同的拒答/「不熟悉」行為，未控制；(d) GPT-4o Search Preview 等帶聯網型號，檢索差異未隔離；(e) 表 1 提及率的「品牌被提及」判定未區分是查詢中已含品牌名（如 "What is [Brand]?"）造成的回聲提及——查詢含品牌名時，模型幾乎必然提及；（此為依查詢模板作出的推測，論文未報告區分）；(f) Bonferroni 說明中「H3 含 4 個子比較」未對應到表 3 的完整回歸輸出；(g) 表 2 中 Chinese brands 的 +65.6pp 與 Zhizibianjie 案例的 65.6% 數字重合，可能是巧合但需核對；(h) 日期自相矛盾（2026 年 12 月 vs arXiv 2025-12）。
- 不同論述間：抽樣 Zhizibianjie 僅 64 個查詢對，95% CI 寬（[46.8%, 81.4%]）。

## 與其他研究的關係
- 支持哪些研究的結論：與「AI 引擎對不同品牌有不同基線可見度」的一般觀察相容；引用 Aggarwal 等（GEO，2309.03409）作為戰術層 GEO 的對照。
- 與哪些研究的結論矛盾：無直接矛盾；但與強調「檢索與第三方來源決定可見度」的研究相比，它把差異全歸因於訓練資料，屬未經驗證的詮釋。
