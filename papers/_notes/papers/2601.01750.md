# 2601.01750 When Attention Becomes Exposure in Generative Search

- 日期：2026-01
- 發表狀態：預印本（未註明；arXiv cs.IR，Springer 格式短文）
- 作者類型：學術（多倫多都會大學、羅馬第一大學）
- 一句話總結：審計 44 家 Web3 企業的生成式搜索引用，發現外部平台（X）上排名前 10 的創作者在引用面板中的每名次份額高於後半部創作者約 4–7 個百分點，且超出隨機基線約 9–10 個百分點。

## 研究問題
- RQ1：Web3 創作者生態的集中度與穩定性。
- RQ2：生成式搜索引擎（GSE）在多大程度引用這些創作者，外部知名度是否提高引用曝光。
- RQ3：哪些因素解釋較高的引用可見度。

## 研究設計
- 系統類型：真實商業引擎（API 與 UI 混合）
- 涉及的引擎和模型，以及測試日期：Grok-4（Live Search）、GPT-5（web search）、Gemini 2.5 Flash（Google grounding）、Perplexity Sonar-Pro。創作者榜單取自 KaitoAI，兩個快照 2025-09-28 與 2025-10-18；查詢的具體執行日期未逐一說明。
- 樣本：44 家 Web3 企業，每家前 100 名創作者（共 3,232 位獨立創作者）；每家 3 條查詢（2 條通用、1 條針對前 10 天內公告的時效性查詢），共 132 條（第 2 節）。
- 對照設計：以「前 10 名 對 後半部（第 51 名以後）」的每名次份額差，以及位置無關的 NCG（歸一化累積增益）對「從企業創作者集合中均勻隨機抽取」的期望值；Grok 的 X 專用模式；Perplexity UI 對 API 對比。
- 評估方式：客觀指標，企業層級 bootstrap（B=1,000）95% 信賴區間；OLS 以聚類穩健標準誤。
- 證據等級：B（真實商業引擎，多查詢，但為單窗口的相關性；只有 Grok 與 Perplexity UI 的曝光結果被有效分析）。

## 主要發現（逐條列出，附數字和出處節號）
1. 創作者社群穩定：20 天內平均 Jaccard 0.67、Kendall's τ 0.75（RQ1，圖 1a）。
2. API 與 UI 不一致：GPT、Gemini、Perplexity 的 API 不返回 X 來源（即使指定域名）；Perplexity UI 在無域名控制時 X 覆蓋為 12.13%，開啟 X 域名包含後 3,698 個唯一來源中有 1,255 個來自 X（33.94%），匹配創作者帳號 134 個（3.62%）。Grok（Web + X）2,223 個唯一 URL 中 1,123 個為 X（50.52%），匹配帳號 152 個（7.02%）；Grok 僅 X 模式 2,194 個 URL 全為 X，匹配帳號 333 個（15.12%）（表 1，RQ2）。
3. 前 10 名相對後半部的每名次曝光優勢：Grok +4.32 pp（95% CI [1.46, 7.51]）、Perplexity +4.79 pp（[2.42, 7.35]）、Grok（僅 X）+7.16 pp（[3.81, 10.93]）（表 2a）。
4. 超出隨機基線的 NCG 提升：Grok +9.39 pp（[2.59, 16.45]，n=37 家企業）、Perplexity +9.94 pp（n=38）、Grok（僅 X）+8.99 pp（n=41）；部分企業因無重疊被排除（表 2a）。
5. 迴歸（log 排名，n=373，偽 R²=0.30）：粉絲數 log(1+f) 係數 −0.44、Jaccard 穩定性 j 係數 −1.62、截距 3.05（對應平均排名約 21），均 p<0.05（表 2b，RQ3）。負係數表示較高排名（曝光更好）。

## 對應原理和管線階段
- 原理編號：[3, 7, 9, 10]。3：第三方（社群平台）來源作為引用來源；7：曝光是分布而非固定排名，且 UI 與 API 結果不同，測量方式影響結論；9：已知度高的來源獲得優勢，形成馬太效應；10：外部注意力貨幣化的創作者經濟與 AI 引用相連。
- 管線階段：檢索、生成/引用、用戶行為/商業
- 新原理候選：「外部注意力（粉絲與榜單排名）向 AI 引用曝光的傳導」，即 AI 引用會放大平台上已有的知名度層級（作者將其表述為曝光偏見，但只證明相關性，未證明因果或機制）。另一點是 API 與 UI 引用面板不同，屬於測量方法學（原理 7）。

## 對實踐的含義
- 有實驗支持的做法：本文無干預實驗。相關性層面：在有 X 來源的引擎中，粉絲多、榜單排名高的創作者更常被引用。
- 作者建議但未經驗證的做法：GSE 公司與研究者應追求 API 與 UI 一致，審計時需納入該差異（第 4 節）。
- 被證明無效或有害的做法：無。

## 局限與效度威脅
- 作者自述：僅限 Web3，可能無法推廣；無法歸因 API 與 UI 差異；創作者知名度用 Kaito 榜單，其評分規則可能內含偏見；曝光指標假設每個引用受到相同注意，未含互動日誌，只是潛在曝光而非實際影響（第 4 節）。
- 榜單分數（Mindshare）本身來自 X 上的互動，與被引用內容的熱度可能同源，因果方向不明。
- 有效分析僅 Grok 與 Perplexity UI（GPT、Gemini API 無 X 來源），且只涵蓋 44 家企業、每家 3 條查詢；重複次數未說明。
- 匹配創作者的引用占比低（3.62%–15.12%），效應建立在少量匹配上。
- 短文，方法細節（如 UI 抓取方式、日期）有限。

## 與其他研究的關係
- 支持哪些研究的結論：引用來源集中於知名來源（如 2512.09483 對 Gini 與流行度的觀察不完全同向，見下）；生成式搜索傾向已有權威（Sharma 等 2024、Venkit 等 2024 論文所引）。
- 與哪些研究的結論矛盾：與 2512.09483 對比：後者發現 LLM-SE 引用較低流行度域名（除 ChatGPT）；本文發現已知創作者被更多引用；兩者領域與度量不同，不算直接矛盾。
