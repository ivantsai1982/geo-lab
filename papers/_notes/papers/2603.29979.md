# 2603.29979 Structural Feature Engineering for Generative Engine Optimization: How Content Structure Shapes Citation Behavior（GEO-SFE）

- 日期：2026-03
- 發表狀態：預印本（arXiv，IEEE 風格排版，未註明會議）
- 作者類型：學術（東京大學、筑波大學、廣島大學、NII）
- 一句話總結：提出把內容結構分為宏觀（標題層級）、中觀（段落與列表／表格）、微觀（強調標記）三層，並宣稱跨六個商用生成引擎平均引用率由 45.0% 升至 52.8%（+17.3%）；但論文對實驗如何執行幾乎沒有說明，多項「實證」數字沒有出處，證據可信度偏低。

## 研究問題
既有 GEO 集中在語義改寫；內容「結構」（獨立於語義）是否系統性影響生成引擎的引用行為？能否建立可量化的結構特徵並做最佳化？（Abstract, §I）

## 研究設計
- 系統類型：商業引擎，但論文未說明如何讓引擎讀取／檢索優化版文章（是手動提供內容、自架頁面或其他方式全文未述）。暫按證據等級 C 標註並註明存疑。
- 涉及的引擎和模型，以及測試日期：Google SGE、Bing Chat（Search-then-Synthesize）；Perplexity AI、Phind（Iterative Refinement）；ChatGPT、Claude（Integrated Search-Generation）（Table III）。未給測試日期、模型版本。註：Google SGE、Bing Chat 的稱呼對應到實際測試的哪個產品，論文沒有交代。
- 樣本：從 GEO-bench 抽 200 篇文章（六個領域各約 33 篇：Biography、Health、Technology、Finance、Travel、Science），配 377 個真實 query，平均文章長度 2,547 詞；200 篇 x 6 平台 x 2 版本 = 2,400 測試案例（§V-A）。每個案例是否重複測量未說明。
- 對照設計：同一文章的原版對優化版（結構轉換）；語義保留以 Bge-m3 相似度驗證，平均 0.843（§V-A）。未與語義類 GEO 方法（引語、統計）對比，也沒有「僅隨機重排結構」之類對照。
- 評估方式：客觀指標 Citation Rate（CR）與 Visibility Score（VS = 0.4 Coverage + 0.3 Position + 0.3 Influence，係數依據未說明）；主觀評估用 G-Eval（Gemini 2.5 Pro 作評判，7 個維度，取 5 次取樣中位數，溫度 0.3）；無人工驗證（§V-A）。
- 證據等級：C（存疑；若引擎內容係手動提供）。主觀部分屬 E（LLM 評判）。整體因方法揭露不足，建議在教材中只作為低權重旁證。

## 主要發現（附出處）
1. 總體：CR 45.0% → 52.8%，VS 0.411 → 0.483，相對提升 +17.3%（paired t-test，n=200，p<0.001，Cohen's d=0.64）（Table IV）。
2. 按架構：Search-then-Synthesize CR 43.7 → 52.1（+19.2%）；Iterative Refinement 52.3 → 59.6（+14.0%）；Integrated Search-Generation 39.1 → 46.8（+19.7%）（Table IV）。文中稱 14–20%。六個平台各自的結果沒有列出。
3. 主觀評估（Gemini 2.5 Pro 打分）：整體平均 +18.5%；Influence +32.0%，Click Probability +31.4%，Diversity +7.2%（Table V）。這是 LLM 對文本的主觀評分，不是真實用戶點擊。
4. 消融（Table VI）：去掉宏觀結構 CR 49.3（-3.5）、去掉中觀 49.7（-3.1）、去掉微觀 51.6（-1.2）；作者換算貢獻比例 44.9% / 39.7% / 15.4%，並據此說「三層獨立運作」。三個單獨移除的降幅加總剛好等於總增益 7.8，這種完全可加的結果在真實交互作用下少見，需謹慎。
5. 五條「數據驅動原則」（§IV-D）：標題深度 3–5、段落 150–300 詞、結構化元素占比 0.25–0.35、強調標記占 5–10%、內部連結密度 0.15–0.20。文中附帶的量化理由（如 >300 詞段落中段注意力下降 31%、<150 詞降低引用機率 23%、列表與表格抽取準確度比散文高 43%）在論文中沒有對應的實驗表格；31% 一項還引用他人文獻 [27]。這些應視為作者主張，而非本文證明。
6. Table II 的架構特定特徵權重（如 Search-then-Synthesize 的 Meta-structure clarity 0.45）以及 gradient boosting 引用預測模型，正文未報告訓練資料、驗證集或預測準確度。

## 對實踐的含義
- 有實驗支持的做法：本文報告結構優化（清晰標題層級、適當分段、列表／表格、關鍵詞強調）能提升引用率，但實驗方法揭露不足，僅作弱支持。與 2602.12187 的方向部分一致（結構化資訊與答案前置有益），但該研究的「結構」指 meta/schema 欄位而非排版。
- 作者建議但未經驗證的做法：五條量化原則的具體數值範圍、架構加權（如 Search-then-Synthesize 偏深層級，heading depth 約 4.5）——文中沒有對這些具體目標值做因果檢驗。
- 被證明無效或有害的做法：未報告。

## 局限與效度威脅
- 引擎存取方式、測試日期、每案例重複次數、query 如何送入引擎都沒有說明；Google SGE 與 Bing Chat 這些名稱對應的實際產品不明。
- 商業引擎具有非確定性，卻只報告單一 p 值（n=200 為文章數，不是重複量測）。
- 沒有對照組控制「僅是文本被改寫」的效應：結構轉換也會改變文本，而語義相似度平均 0.843，低於文中自設的句級門檻 0.95（不同層級的門檻，論文未澄清）。
- 引用預測模型與權重的依據缺失；多個數字（31%、23%、43%）無出處。
- 主觀評估由 LLM 評判，且與被優化目標接近；G-Eval 分數「正規化以匹配 Position-Adjusted Word Count 分佈」，意義不明。
- 沒有 Limitations 小節。
- 作者為學術機構，未見利益衝突。
