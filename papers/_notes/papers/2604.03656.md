## 主要發現（逐條列出，附數字和出處節號）
1. 【理論推導，非實驗】信心衰減式：C(t,D)=C0·exp(−λt)·(1−αH/log|V|)（式 3，§2.3）。附錄 A 在假設 λ>0、熵非遞減下「證明」C 單調遞減且極限為 0。該結論是假設的直接結果，λ、α 均未從數據估計。
2. 作者聲稱靜態 Schema.org 注入只降低初始熵、對 λ 無影響（§2.4）。這是模型內的斷言，未用實測驗證。
3. IAR 式（式 4）把優化動作特徵、以及生成圖與真值圖的 GED 懲罰放進邏輯迴歸；沒有給出任何 β、γ 的估計值或擬合結果。
4. DAH 協議：LLM 只做意圖路由，將 Intent State Tensor ⟨u,c,p⟩ 交給專有 Agent（§4.1；附錄 C JSON 規格）。§4.3 案例以敘述方式聲稱「幻覺率被物理消除」，無測量。
5. 摘要稱以 EasyNote 驗證，「垂直任務幻覺率降至近零」，但正文未見對應的實驗章節、表格或數字（本人通讀全文所見）。
