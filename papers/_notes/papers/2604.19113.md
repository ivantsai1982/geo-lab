# 2604.19113 Think Before Writing: Feature-Level Multi-Objective Optimization for Generative Citation Visibility (FeatGEO)

- 日期：2026-04
- 發表狀態：預印本（未註明；版式為 ACL 風格，但文中未寫會議名）
- 作者類型：學術（南京信息工程大學）
- 一句話總結：把網頁抽象成 13 個結構／內容／語言特徵，用 NSGA-II 在特徵空間搜索、再由 LLM 生成整頁；在 GEO-Bench 的簡化 RAG 管線上，可見度顯著高於原始 GEO 的 token 級啟發式（後者在 LLM 生成的廣告頁上反而低於未改寫基線）。

## 研究問題
token 級文字改寫（GEO、AutoGEO）不穩定且缺乏可解釋性；能否在「主題級」用可解釋特徵做可見度與品質的多目標優化？

## 研究設計
- 系統類型：可複現 RAG 管線（GEO 原文的兩階段：Google 搜索取 top-5 + 生成器帶引用；並向 5 個來源之外「注入」一個廣告頁）。
- 涉及的引擎和模型，以及測試日期：答案生成器 GPT-4o-mini、Gemini-2.5-flash、Qwen-plus；頁面生成器固定 GPT-4o-mini（§4.1）；§4.7 另用 Qwen3-4B/8B/14B 作頁面生成器。測試日期未註明。
- 樣本：GEO-Bench（10K 查詢、25 領域，§4.1）；未清楚說明實際跑了多少查詢。NSGA-II 種群 8、8 代，每個配置評估 5 次（§4.1）；§4.5 擴展為 50 個體 100 代。
- 對照設計：Baseline（未改寫廣告頁）、9 種 GEO 啟發式、AutoGEO-global、AutoGEO-instance。
- 評估方式：可見度為詞位置加權引用分（客觀計算）；品質為 LLM 評判（G-Eval 式，7 維，§4.1），並用 Gemini-2.5-flash 與 Claude-3.5-Sonnet 交叉評判（§4.3，無人工驗證）。
- 證據等級：E（固定候選集、由 LLM 生成的廣告頁、LLM 評判品質；未涉及真實引擎的檢索）

## 主要發現（逐條列出，附數字和出處節號）
1. 表 2（§4.2）：FeatGEO 的最高可見度方案為 GPT-4o-mini 18.31%（基線 13.34%，+37%）、Gemini 15.35%（基線 8.89%，+73%）、Qwen-plus 10.17%（基線 5.20%，+96%）；品質 81.52 / 76.14 / 77.12，對應基線 79.17 / 75.59 / 76.81。
2. 表 2：9 種 token 級 GEO 啟發式在全部三個引擎上都低於未改寫基線（如 GPT-4o-mini 為 10.92–12.21% vs 13.34%；Gemini 4.62–5.62% vs 8.89%；Qwen-plus 2.75–3.72% vs 5.20%）。AutoGEO-instance 亦低於基線（12.12 / 7.04 / 4.25）。
3. 表 4（§4.4）：同樣的啟發式用在「人寫」頁面上平均 +0.99（18.72%→19.71%），AutoGEO-global +4.13、Statistics Addition +2.33、Unique Words −2.38。作者解釋為「飽和效應」——已流暢的 LLM 生成頁再改寫反而破壞自然性（此為作者解釋，未直接檢驗）。
4. 表 3（§4.3）：換用 Gemini 與 Claude 當品質評判，FeatGEO 仍排第一（75.28、72.63），分別領先最強基線 4.26 與 0.53 分。
5. §4.6 / 圖 4 消融（每次把一個特徵鎖到最小值）：Statistics 與 Cite Sources 貢獻最大（圖中最大 +0.0252，其餘多為個位數千分位）；Unique Info 部分情況略降低可見度；結構特徵貢獻穩定但較小；特徵間變異大、依賴組合。
6. §4.5 / 表 5：可見度與品質存在取捨且因主題而異（教育題：方案 A 可見度 23.7%、品質 87.8；方案 B 8.4%、92.7）。高可見度方案有較高的引文／引語／流暢度，結構特徵（列表、標題、長度）在高品質方案更強。僅為單一查詢樣本的案例。
7. §4.7 / 圖 5：頁面生成器換成 Qwen3-4B/8B/14B，FeatGEO 可見度約 13.6/13.6/13.7，基線 9.5/8.0/9.0（讀圖數值），優勢穩定。
8. 附錄 F：每個查詢平均 1,720.8 秒、366 次 API 調用、約 1.0M prompt tokens；GA 階段佔時間 87.8%。

## 對應原理和管線階段
- 原理編號：[4, 5, 6]。5：可抽取證據（統計、引用來源、引語）與結構；4：條件於已進入上下文；9：優化與操縱走同一通道——廣告頁模板含「每段提品牌、Urgency、Testimonial」等促銷指令（附錄 B）。
- 管線階段：生成/引用（且僅此階段；檢索被固定）
- 新原理候選：無。可補充「已被生成／優化過的內容再改寫有飽和或負效應」（僅單一基準支持）。

## 對實踐的含義
- 有實驗支持的做法（僅限此簡化管線與基準）：在整頁層面提高統計數據與來源引用密度、引語、標題與列表等；用主題級而非單查詢級優化。
- 作者建議但未經驗證的做法：特徵配置「編碼與模型無關的原則」（僅測了頁面生成器換尺寸，答案生成器固定）；結論稱 LLM 引用更受高層話語組織影響而非詞彙線索（為作者對一個基準的推論）。
- 被證明無效或有害的做法：在此設置下 Keyword Stuffing、Unique Words 等 token 級改寫不僅沒提升，還低於基線；Unique Words 在人寫頁上也 −2.38（表 4）。

## 局限與效度威脅
- 作者自述（Limitations）：候選集固定（5 個檢索頁 + 1 個廣告頁），假設廣告頁已被檢索；適應度來自 LLM 生成引擎與自動引用解析；品質由 LLM 評判；成本高。
- 廣告頁由 GPT-4o-mini 生成且提示含強促銷指令，與真實網站差別大；廣告頁與「競爭頁」的體裁不同。
- 基線低於原 GEO 論文結論（與 GEO 原文報告的提升相反），說明結論對設置敏感。
- 不報告顯著性檢驗或置信區間；不清楚使用的查詢子集大小。
- FeatGEO 是對每個主題「用引擎反饋做搜索」，優化時已用同一引擎測評，存在過擬合到該測試引擎與該查詢分佈的風險。

## 與其他研究的關係
- 支持哪些研究的結論：與 AutoGEO（2510.11438，Wu et al.）方向一致——引擎偏好內容層面而非詞彙；支持「引用行為有系統偏好」的說法（Algaba et al.）。
- 與哪些研究的結論矛盾：與 GEO 原文（2311.09735）相反——本文複現下其 9 種方法多低於基線；作者歸因為基準規模與內容基礎品質差異。
