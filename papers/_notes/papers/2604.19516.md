# 2604.19516 From Experience to Skill: Multi-Agent Generative Engine Optimization via Reusable Strategy Learning (MAGEO)

- 日期：2026-04
- 發表狀態：預印本（未註明；版式為 ACL 風格，文中未寫會議名）
- 作者類型：學術（杭州電子科技大學等）
- 一句話總結：多 Agent（偏好／規劃／編輯／評估）迭代改寫目標文檔，並把成功的編輯模式沉澱為分引擎的「技能庫」；在凍結檢索列表的雙分支對照下，可見度（WLV）相對單一啟發式提高數倍，但主要依賴 LLM 評判的自定指標。

## 研究問題
GEO 方法逐個實例優化、不能積累和遷移策略；能否用策略學習加上保真度感知的評估，得到可跨任務、跨引擎複用的優化技能？

## 研究設計
- 系統類型：商業引擎但手動提供 URL（凍結檢索列表，只替換其中一個文檔）。實質上是固定上下文設計，未走真實檢索階段。
- 涉及的引擎和模型，以及測試日期：GPT-5.2、Gemini-3 Pro、Qwen-3 Max（§5.1）；基準構建用 Tavily Search API 取 top-10 與 Gemini-3 Pro 反向生成查詢（§4.1）；測試日期未註明。
- 樣本：MSME-GEO-Bench（作者自建，5 大領域 15 子類；具體查詢數在讀到的正文段落未給出）與 GEO-Bench。人工驗證：100 條抽樣四元組、3 名 NLP 背景標註者；另 50 對成對比較（§5.2）。
- 對照設計：Twin-Branch——同一查詢、同一凍結檢索列表，基線分支不改，優化分支把隨機抽取的一個目標文檔換成優化版 d*（§3.1）。基線：GEO 官方 9 個啟發式、及其 2/3/4 組合（表 5）。消融：去掉 Engine Preference、去掉 Skill Bank（表 1、3、5）。
- 評估方式：自定義指標 DSV-CF（SSV：WLV、DPA、CP、SI；ISI：AA、FA、KC、AD；式 2，λ=0.5、γ=0.5），其中相當一部分由 LLM 評判；與人工的 Spearman ρ：DSV-CF 0.81、WLV 0.79、CF 0.74（表 2）；成對一致率 81.5%。
- 證據等級：E（固定上下文、LLM 評判為主、自建基準；有小規模人工驗證）

## 主要發現（逐條列出，附數字和出處節號）
1. §5.3 / 表 4、5：MSME-GEO-Bench + GPT-5.2 上，MAGEO WLV 4.52（Lite 3.95），未優化基線為 1.00（指標經歸一化，基線=1.00），最強單一啟發式 More Quotes 為 1.33。Gemini-3 Pro 為 5.30（正文）；Qwen-3 Max 上 WLV/DPA 由 1.00 升至 3.84（§5.3），啟發式 ≤1.33。
2. §5.7 / 表 5：組合四個最強啟發式（MQ+TT+CS+Au）WLV 1.90，仍遠低於 MAGEO 的 4.52；作者據此稱收益不可歸為規則相加。
3. §5.4 消融：去掉引擎偏好模組使 GPT-5.2 上下降約 19%，去掉 Skill Bank 約下降 13%（文中「~19%」「~13%」，指標基準未明確）。表 5 中 w/o Engine Preference 為 WLV 2.08、w/o Skill Bank 1.41。
4. §5.6 / 表 4：成本——GEO Quote 5.7k tokens、12.3s；MAGEO Lite 8.9k（2.9×）、18.1s；Full 12.4k（4.0×）、38.7s；虛假引用比例 CF 由 0.058（GEO Quote）降至 0.047（Lite）、0.043（Full）；配對 t 檢驗 p<1e−8（vs GEO Quote）。
5. §5.5 / 圖 4：迭代到約第 5 版達峰值，其後收益遞減且忠實度略降（作者稱「過度優化疲勞」）。
6. §5.4：引擎偏好差異為定性描述——Gemini-3 Pro 偏好緊湊結構化證據、GPT-5.2 偏權威式且引用格式較重、Qwen-3 Max 偏說教式與安全導向；這是作者的定性觀察，文中僅舉「Gemini 對醫療建議偏好項目符號」為技能示例，未給量化證據。
7. §5.3：Keyword Optimization 等啟發式會觸發幻覺懲罰（作者觀察）；MAGEO 的 FA（文檔級）>7.05。表 1 中多數單一啟發式與未優化基線差異很小（如 WLV 0.78–1.33）。

## 對應原理和管線階段
- 原理編號：[4, 5, 6, 9]。5：結構化證據補全、引用格式；6：DSV-CF 明確用歸因準確度（AA）懲罰錯誤引用，區分「被引用」與「被正確使用」；9：優化與保真並存、多 Agent 生成式改寫屬優化亦可被濫用；7：Twin-Branch 只是單次抽樣的對照。
- 管線階段：生成/引用、吸收/保真
- 新原理候選：「引擎特異偏好」（各引擎偏好的內容風格不同，需分引擎優化）——僅有作者定性觀察與消融支持。

## 對實踐的含義
- 有實驗支持的做法（限此設置）：迭代式、保真度受控的改寫優於單一啟發式；補全缺失證據、結構修復（§5.5 稱早期收益主要來自此，為作者解讀）；不要過度迭代（約 5 輪後收益遞減）。
- 作者建議但未經驗證的做法：在高風險場景補充人工抽檢；Lite 為成本敏感首選；技能庫可跨引擎／場景複用（作者承認未做未見場景的泛化分析，Limitations）。
- 被證明無效或有害的做法：Keyword Optimization 等單一詞彙型啟發式在此基準上提升微弱，且可能引入幻覺懲罰（§5.3）。

## 局限與效度威脅
- 作者自述：成本高；基準規模有限；Gemini-3 Pro 同時用於查詢反向生成與標註（模型偏差）；未做技能泛化與學習曲線；引擎演化會使技能過時；僅文字。
- 評估以 LLM 評判為主，Evaluator Agent 也用 LLM 預測 DSV-CF 增益（優化目標與評估目標同源）；WLV 基線歸一化為 1.00 使絕對量難以解讀。
- 檢索列表凍結，且目標文檔本身是「反向生成查詢」所對應的源文檔，天然與查詢高度相關。
- 表 1 有兩個數據集，我在讀取時無法完全確認各欄位的數據集歸屬，故 GPT-5.2 的主要結果以正文與表 4／5 的 4.52 為準。

## 與其他研究的關係
- 支持哪些研究的結論：與 AutoGEO（Wu et al. 2025）的「引擎偏好可學習」方向一致；與 GEO 原文一致的是關鍵詞堆砌無效。
- 與哪些研究的結論矛盾：與 2604.19113（FeatGEO）對比，本文報告單一啟發式基本不掉（接近或略高於基線），而 FeatGEO 報告多低於基線；兩者設置（是否生成廣告頁）不同。
