# 2605.12887 EcoGEO: Trajectory-Aware Evidence Ecosystems for Web-Enabled LLM Search Agents (TRACE)

- 日期：2026-05（v2 為 2026-07-01）
- 發表狀態：預印本（文中標「Preprint」）
- 作者類型：學術（上海科技大學）
- 一句話總結：對會多步搜索與爬取的 GPT-5.1 搜索 Agent，用一個「導航入口頁 + 六種來源風格且互相鏈接、屬性一致的支持頁」證據生態，讓虛構產品被推薦的比率明顯高於單頁與單頁 GEO 方法；同時它本質上是一種「偽造多來源共識」的操縱手法。

## 研究問題
在會發起搜索、爬取頁面、跟隨鏈接、改寫查詢的網頁 Agent 場景，GEO 的作用單位是單頁還是整個證據環境？

## 研究設計
- 系統類型：可複現 RAG／Agent 管線（自建搜索 Agent：GPT-5.1 + Google Search API + Crawl4AI），並採用受控曝光——初始搜索固定為「9+1」，即 9 條真實 Google 結果加 1 條合成結果固定插入第 5 位（§4.1）。等於跳過真實的索引與排名階段。
- 涉及的引擎和模型，以及測試日期：GPT-5.1（溫度 0，最多 10 步，兩至五次搜索、兩至五次爬取；附錄 B）；最終答案由 GPT-5.4-mini 判定；測試日期未註明。
- 樣本：OPR-Bench 共 3,124 個查詢-虛構產品對：SafeSearch 64、E-Commerce 121、E-GEO 2,939（§1、附錄 A 表 3）；主實驗只用 E-GEO 前 1,000 個（附錄 A）。消融在「兩個小數據集」上進行（§5.2）。重複次數未說明（溫度 0、看似單次運行）。
- 對照設計：單頁基線（官方風格單頁）、頁面級 GEO 方法 C-SEO、E-GEO、AutoGEO，與 TRACE；消融為 Uncoordinated / Coordinated / TRACE，且強制第一次必須爬取指定合成頁（§5.2）。
- 評估方式：客觀行為指標（爬取率、跟進搜索、內部鏈接爬取）＋ LLM 判定最終答案是否推薦目標（§4.3、附錄 B），未報告人工驗證。
- 證據等級：D（可複現的完整 Agent 管線，含搜索與爬取，但曝光位置被人工固定、產品為虛構、無重複與顯著性檢驗；判定含 LLM）

## 主要發現（逐條列出，附數字和出處節號）
1. 表 1 / §5.1：最終目標推薦率，TRACE 為 SafeSearch 67.2%、E-Commerce 71.9%、E-GEO 73.9%；單頁基線 35.9 / 56.2 / 59.0。相對最強基線的絕對增益為 31.3、15.7、14.9 個百分點（§5.1）。
2. 表 1：頁面級 GEO 並未穩定優於單頁基線——SafeSearch 上 C-SEO 35.9、E-GEO 35.9、AutoGEO 28.1（基線 35.9）；E-Commerce 上 54.5 / 55.4 / 43.8（基線 56.2）；E-GEO 上 56.0 / 58.8 / 53.7（基線 59.0）。AutoGEO 在所有三個數據集都低於基線。
3. 表 1：初始目標結果爬取率 TRACE 42.2 / 61.2 / 48.9（單頁基線 14.1 / 43.8 / 27.0）；目標特定的第二次搜索 29.7 / 23.1 / 21.9（基線 18.8 / 14.9 / 11.0）。作者解讀為導航入口頁改變了搜索軌跡（機制解讀，觀察為相關）。
4. 表 1：內部鏈接爬取僅 TRACE 出現（9.4 / 19.0 / 20.4%）；單頁方法因沒有內鏈為「/」。
5. 表 1：後續目標結果爬取（Follow-Up Target-Result Crawl）TRACE 在 E-Commerce（15.7 vs 基線 21.5）與 E-GEO（24.9 vs 31.9）反而較低；作者解釋單頁方法重複曝光同一頁，因此延遲爬取機率上升（§5.1）。
6. 表 2 / §5.2（強制首爬）：目標推薦率 Uncoordinated→Coordinated→TRACE 為 SafeSearch 75.0→82.8→89.1、E-Commerce 81.8→87.6→93.4。Coordinated 到 TRACE 主要是內部鏈接爬取由 0.0→29.7（SafeSearch）、6.6→25.6（E-Commerce）。目標特定第二次搜索在協調化後反而下降（54.7→40.6；46.3→37.2）。
7. 作者稱增益來自「塑造 Agent 證據獲取過程」而非「單純增加相關內容」（摘要與 §6）；但實驗沒有控制「頁面數量」的純內容量對照（多頁 vs 多頁但無鏈接已部分覆蓋，即 Uncoordinated）。

## 對應原理和管線階段
- 原理編號：[8, 9, 3, 2]。8：Agent 實際爬取、跟隨鏈接；9：多頁偽造證據屬操縱，防禦（跨獨立來源驗證）僅在未來工作提到；3：第三方來源風格（評測、論壇、新聞）被用作共識；2：Agent 的跟進搜索與查詢改寫成為影響通道。
- 管線階段：檢索、重排/上下文、生成/引用
- 新原理候選：「軌跡級影響／證據生態」——影響取決於 Agent 的多步瀏覽軌跡（入口頁、內鏈、跨頁一致性），而非單頁內容。可作為 Principle 8 的延伸。

## 對實踐的含義
- 有實驗支持的做法（限此受控設置，且為虛構產品）：多個來源風格互補、屬性一致並互相鏈接的證據環境，優於單頁優化；導航入口頁增加內鏈爬取。
- 作者建議但未經驗證的做法：未來研究支持頁規模、入口排名、交叉鏈接密度、摘要設計；開發能促使 Agent 跨更多獨立來源驗證的防禦。
- 被證明無效或有害的做法：在此設置中，頁面級 GEO 改寫（C-SEO、E-GEO、AutoGEO）並不比未優化單頁更好，AutoGEO 更低（表 1）。
- 倫理：作者聲明不主張在真實系統應用；為安全不公開完整代碼，僅接受後公開基準（Ethical Considerations）。從實踐角度，這是對 Agent 的偽造證據攻擊，可作防禦教材的反例。

## 局限與效度威脅
- 作者自述：虛構產品受控環境，無法反映排名變動、自然發現、時間變化、商業來源互動；只檢驗一族生態設計（§6）。
- 首輪目標結果被固定在第 5 位，實際上沒有測「能否被索引／排到那個位置」；跟進搜索中 TRACE 用「生態內檢索」（本地語義排序）回覆目標特定搜索，而基線退化為同一頁，兩者不完全對稱（作者承認為方法定義所致）。
- 溫度 0、未報告重複與置信區間；SafeSearch 僅 64 題（百分比每題約 1.6 個點）；消融只用兩個小數據集且強制首爬。
- 最終判定含 LLM（GPT-5.4-mini），無人工驗證報告。
- 單一 Agent 後端 GPT-5.1；跨模型是否成立未知。

## 與其他研究的關係
- 支持哪些研究的結論：與「單頁改寫收益有限、跨來源共識更有影響」的方向一致；引用 SafeSearch（紅隊測試 LLM 搜索 Agent）的威脅模型。
- 與哪些研究的結論矛盾：與 AutoGEO 原文報告的提升不一致（本設置下 AutoGEO 低於基線）；與 2604.19113 的 FeatGEO 一樣，顯示原有頁面級 GEO 方法在新設置中不穩定。
