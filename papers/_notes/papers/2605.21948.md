# 2605.21948 SCI-Defense: Defending Manipulation Attacks from Generative Engine Optimization

- 日期：2026-05
- 發表狀態：預印本（NeurIPS 格式，標註 "Preprint."）
- 作者類型：混合（UIUC 學術作者，其中一位標 Amazon；作者行另列 topcited.ai，論文未說明其性質，可能是 GEO/AI 可見度相關服務，需留意利益衝突，但屬推測）
- 一句話總結：提出三件式偵測防禦（GPT-2 困惑度、GPT-4o 語義完整性評分、候選間相似度），在 CORE 的 600 個商品描述資料集上對字串、推理、評論三類注入攻擊達 Precision 1.000、FPR 0.000，但作者自設的 5 種「事實相關性膨脹」黑箱攻擊全部繞過（Block@3=0.000）。

## 研究問題
現有防禦（困惑度過濾、內容安全分類器、釋義改寫）能否擋住針對 LLM 排序的 GEO 操縱攻擊？若不行，能否設計專門針對「說服結構」的防禦，並找出它的盲點（§1）？

## 研究設計
- 系統類型：固定上下文 LLM／防禦偵測管線（注入文字附加到商品描述，防禦把可疑商品移到排序末位）
- 涉及的引擎和模型，以及測試日期：偵測用 GPT-2（困惑度）、GPT-4o（SIS 評分）與某嵌入模型（ICD，模型名在我讀到的部分未載明）；攻擊來自 CORE（arXiv 2602.03608，署名 Anonymous）的三種：String、Reasoning、Review（§3.1）。被攻擊的 LLM 排序器與測試日期，正文未見清楚說明。
- 樣本：ProductBench（來自 CORE）600 個商品描述，6 類各 100，每個描述各受 3 種攻擊，共 1,800 個攻擊實例；另用 600 段 MS MARCO 網頁段落（6 個資訊領域各 100）測泛化（§4.1）。權重、閾值在 Automotive 的 20% 驗證集上以網格搜尋定出（在 FPR=0 的約束下最大化 F1）。新攻擊測試 n=30（Automotive），跨域驗證用 Toys & Games；消融 n=50；釋義比較 n=30。
- 對照設計：三個基線：PPL 過濾、SafetyClf（如 Llama Guard 類安全分類器）、釋義改寫（GPT-4o）；元件消融；SIS 四維度移除消融（§4.4–4.6）。
- 評估方式：客觀指標（Recall、Precision、F1、FPR、Block@k），但核心偵測器 SIS 依賴 GPT-4o 評判（LLM 評判，無人工驗證）。
- 證據等級：E

## 主要發現（逐條列出，附數字和出處節號）
1. 主結果（Table 2、§4.3）：在 600 個 Amazon 商品描述上 Precision 1.000、FPR 0.000；String 攻擊 Recall 1.00；Reasoning 平均 0.952；Review 平均 0.830。MS MARCO 上 String 仍 1.00，Reasoning 平均 0.785，Review 平均 0.008（近乎零）。作者解釋為：網頁段落缺乏權威堆疊、比較宣稱等 SIS 針對的訊號，且 Review 型攻擊在資訊檢索情境本身就較無效（此為作者推測）。
2. 基線全部失效（Table 3、§4.4）：PPL 過濾只擋 String（Recall 1.00），對 Reasoning 與 Review 為 0；SafetyClf 對三類都是 0；釋義改寫三類都是 0 且對合法描述有 2.7% 的誤傷（FPR 0.027）；基線 Block@3=Block@5=0.000，SCI-Defense 為 1.000。
3. 元件互補（Table 4，n=50）：PPL 只對 String 有效（F1 1.000）；SIS 對 Reasoning/Review F1 1.000、String 0；ICD 單獨 FPR 0.74（不可用）；完整系統 F1 0.990、FPR 0.02（此表與主結果 FPR 0.000 的差別，來自 n=50 的 Automotive 消融）。
4. 校準教訓（§4.2）：初始 τs=0.42 使 FPR≈0.85（約 170/200 合法 Automotive 描述被誤標）；提高至 0.55 並限縮 boost 條件後 FPR 降為 0。閾值是在同資料集的驗證切分上調定的，作者建議各領域分別校準。
5. 釋義改寫的各種提示變體最佳僅 Block@3 0.694（Conservative Summary），「白箱」提示（明說三種攻擊）與通用改寫表現相同 0.389（Table 5，n=30）。
6. 新黑箱攻擊（§5、Table 7，n=30 Automotive）：SEO Stuffing、Authority Injection、Specification Amplification、Use-Case Saturation、Hybrid Stealth 五種全部 Block@3=0.000，SIS 平均分 0.353–0.418，低於 τs=0.55；只有 Fake Social Proof 被抓到（偵測率 0.833，Block@3 0.857）。在 Toys & Games 上得到類似結論。作者稱這是「語義相關性膨脹」的結構性盲點。
7. 誤漏分析（§4.7）：Reasoning 有 29/600 漏報；Review 有 102/600 漏報，其中 74.7% 的最終分數落在 [0.45, 0.55)。作者指出漏報中 5/29（Reasoning）與 6/102（Review）是實際成功操縱排名的攻擊。
8. 內部不一致：§4.3 稱 Block@3 在全部 18 個類別-攻擊組合都是 1.000，但 §4.7 又承認漏報中有實際成功操縱排名的案例；論文未調和二者（可能是 Block@k 的定義或取樣不同，我們無法確認）。「DefPSR@3」在我讀到的文字中也未見定義（Table 7 中五個未被偵測的攻擊值皆為 0.233）。
9. 描述恢復（Table 6，n=30）：LLM-Extraction 平均相似度 0.893；PPL 截斷對 String 最佳 0.988。

## 對應原理和管線階段
- 原理編號：[9, 4, 5]。9：防禦機制，且「優化與操縱走同一條通道」在此有明確體現：本文防禦專盯說服信號，攻擊者改用堆疊事實/規格/使用場景（看似正常的相關性資訊）即可繞過；4/5：商品描述中的可抽取事實與相關性訊號影響排序。
- 管線階段：檢索之後的重排/上下文；生成/引用（LLM 排序）
- 新原理候選：「正當優化與操縱的界線在語義上難以區分」，防禦若以說服語氣為特徵，就會把事實相關性膨脹視為正常內容，這與原理 9 中的「同一通道」一致，可作為其小節。

## 對實踐的含義
- 有實驗支持的做法：（防守方，受限於 CORE 的三種攻擊與 ProductBench）PPL＋GPT-4o 語義評分＋候選間相似度的組合在該資料上零誤傷；PPL 對亂碼型字串攻擊有效；單純釋義改寫、安全分類器無效。
- 作者建議但未經驗證的做法：以關鍵詞密度偵測與查詢相關性異常偵測補盲點（需查詢存取；§6）；各領域各自校準閾值並把 FPR=0 當硬約束。
- 被證明無效或有害的做法：PPL-only 過濾對流暢攻擊；安全分類器（無害內容）；釋義改寫（保留意圖，且有 2.7% FPR）。另外：對「規格與使用場景堆疊」的做法（Specification Amplification、Use-Case Saturation）在此防禦下未被偵測；但論文並未展示這些攻擊對真實 LLM 排序器的成功率之外的細節（DefPSR@3 0.233 的含義不明），所以不能直接當作「有效的優化方法」。

## 局限與效度威脅
- 作者自述：殘餘盲點（語義相關性膨脹）無法靠調閾值消除；需查詢資訊才能補上。
- 我們的觀察：(a) FPR=0 是在與合法資料同源、且用同一資料集切分校準閾值下取得，泛化證據有限；「合法描述」是 ProductBench 中原始描述，沒有真實賣家常用的誇大宣傳文案，可能低估誤傷；(b) 攻擊由 CORE 生成，非針對 SCI-Defense 的自適應攻擊；自設攻擊樣本僅 n=30；(c) 核心偵測依賴 GPT-4o 的評分，成本與可複現性未討論；(d) 懲罰策略「移到最後」對真實電商可能導致合法商品被誤降；(e) MS MARCO 上 Review 近零召回，顯示方法主要適用於帶說服語氣的電商描述；(f) 被攻擊的排序器、成功率基線沒有清楚呈現；(g) CORE 為匿名作者、未經確認的來源論文；(h) 有前述內部不一致。

## 與其他研究的關係
- 支持哪些研究的結論：Alon & Kamfonas 2023 對困惑度過濾只能擋亂碼型攻擊的判斷；2504.05804 指出的 STS 亂碼易被 PPL 偵測，與此處 String 攻擊 PPL>500 一致。
- 與哪些研究的結論矛盾：與「釋義改寫是有效基線防禦」（Jain 等 2023 對 jailbreak 的結論）不一致，作者認為 GEO 的意圖在釋義下被保留。與 2504.05804 的設定形成攻防對照：StealthRank 明確優化流暢度與避免宣傳詞，而本文的 SIS 抓的是說服結構（不是宣傳詞），兩者尚未互相測試。
