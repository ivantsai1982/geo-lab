# 2606.09204 The Injection Paradox: Brand-Level Suppression in Safety-Trained LLM Recommendations via RAG Context Injection

- 日期：2026-06（v2：2026-07）
- 發表狀態：工作坊（ICML 2026 Workshop on Failure Modes in Agentic AI, FAGEN；非存檔）
- 作者類型：學術/獨立研究者（單一作者，Independent Researcher）
- 一句話總結：在固定 40 文檔上下文的耳機推薦任務中，插入提示注入使 Claude Sonnet/Opus 對目標品牌的 top-2 推薦率低於無注入基線（Opus 54%→8%），且抑制波及同品牌未被修改的文檔，而 GPT 系列相反（被推升）。

## 研究問題
安全訓練（Constitutional AI 等）對 RAG 上下文中的間接提示注入，是否會產生副作用，使注入反而抑制目標品牌？（§1）

## 研究設計
- 系統類型：固定上下文 LLM（模擬 RAG 的生成階段：40 篇文檔全部直接放入上下文，檢索/重排/分塊不在範圍，§3.1、§6）
- 涉及的引擎和模型，以及測試日期：GPT-4o-mini、GPT-5-nano、GPT-5-mini、GPT-5.4；Claude Haiku 4.5、Sonnet 4.6、Opus 4.6；溫度 1.0（附錄 D 測 0.3）；資料收集 2026-02 至 2026-05（附錄 H）
- 樣本：40 文檔、9 品牌（韓文 Naver 部落格/產品頁，全實驗使用韓語）；目標 Edifier NeoBuds Pro 3（4 篇文檔，只改其中 blog_210）；共 4,500+ 次試驗；GPT-4o-mini 與 Haiku 每格 100 次，Sonnet/Opus 每格 50 次（§3.1）
- 對照設計：基線 / Implicit（情緒、時間、假權威）/ Injection（僅 T1 注入，長度約 +10%）/ Combined（注入+3× 擴寫+其他）；反事實（移除注入文檔換成 Sennheiser）；跨品牌（Apple、Galaxy）；長度混淆排除；D1–D6 緩解消融
- 評估方式：客觀指標（目標品牌是否進入 JSON 輸出 top-2），Fisher 精確檢驗、Wilson CI、Cohen's h
- 證據等級：E（固定上下文，合成改寫文檔，單一領域單一語言）

## 主要發現（逐條列出，附數字和出處節號）
1. 表 2（top-2 命中率，基線→Injection）：GPT-4o-mini 17→40%（+23pp，p<.001）；Haiku 14→12%（n.s.，p=.834）；Sonnet 26→8%（−18pp，p=.031，未校正）；Opus 54→8%（−46pp，p<.001）。Combined：Opus 0%（0/50，CI [0.0, 7.1]），Sonnet 2%（§3.3.1）。
2. GPT 四個型號在 Combined 下均為推升（+50、+68、+56、+66pp）（附錄 C 表 8）。
3. 拒絕不是機制：Claude 六格中明確拒答為 0，抑制表現為「靜默降級」，目標被其他品牌取代（§3.3.1、附錄 G）。
4. 品牌級傳播（反事實）：僅 1/4 Edifier 文檔被注入，Opus 命中率從「3 篇基線（移除 blog_210）28%」降到 Combined 0%（p<.001）；Sonnet 8%→2%。作者稱「Worse-Than-Absent」（§3.3.2 表 3）。
5. 跨品牌（Combined，表 4/6）：Edifier Haiku +34、Sonnet −24、Opus −54pp；Apple +9/−14（n.s.）/−34pp；Galaxy +24/+12/−14pp（n.s.，p=.176）。趨勢方向一致，但 Sonnet 的 Apple 與 Galaxy、Opus 的 Galaxy 不顯著。
6. 長度混淆排除：用三倍長度的 Edifier 複合文檔取代，Opus +12pp、Sonnet +14pp（均 n.s.），與注入方向相反（附錄 E）。
7. 非全語料不信任：注入放在 Apple 文檔時，Edifier 命中率無顯著變化（Haiku 14→14；Sonnet 26→30；Opus 54→46，全部 p>.4）（§3.3.4）。
8. 緩解：無一恢復基線。Opus：D3 34%、D4（僅給客觀規格錨點）36%，仍低於 54%；D5 少樣本 0%；D6b（CoT 逐文檔判斷）100% 檢出注入，但目標僅 4%（Opus）、0%（Sonnet）；降溫至 0.3 差異 ≤8pp（§4.2、表 5、附錄 D）。
9. 「識別-行為分離」：Opus 96% 的試驗中宣稱會忽略操縱、公平評判，卻仍不推薦目標（§4.2.1）。

## 對應原理和管線階段
- 原理編號：[6, 9]。6：被檢索不等於被使用，且模型內部安全行為會改變使用方式；9：操縱與防禦走同一通道，防禦本身成為攻擊面（reverse attack）。
- 管線階段：生成/引用、吸收/保真
- 新原理候選：「防禦副作用/反向攻擊」——安全訓練對注入文本的反應可能懲罰整個實體（品牌），攻擊者可在競品文檔中植入注入以抑制對手。現有 10 條未涵蓋（原理 9 只涵蓋競爭與防禦，未涵蓋防禦反噬）。作者亦稱其為「技術上可能」，非已部署驗證。

## 對實踐的含義
- 有實驗支持的做法：（防禦側）在系統提示中提供客觀決策標準（規格清單）可部分恢復（Opus D4 36% vs 8%，但仍低於 54%）；Claude 系列下，顯式的提示注入是有風險的（提示注入在 Sonnet/Opus 下降低推薦）。
- 作者建議但未經驗證的做法：將此現象擴展到 agent 鏈中的下游動作（作者明說留待未來）；機制「品牌級信任懲罰」僅為假說。
- 被證明無效或有害的做法：在文檔中嵌入提示注入（Claude Sonnet/Opus 下反而抑制，GPT 系列下則推升）；D1、D2、D5、D6 提示級緩解無效。

## 局限與效度威脅
- 作者自述：靜態語料設置，無檢索/分塊；單一領域（無線耳機）、單一語言（韓語）；機制未定（表層關鍵詞解釋同樣可預測）；Claude 內部規模與對齊混淆（Haiku 不受影響）；其他家族泛化未知；Sonnet 的 p=.031 未校正，Opus 為主要對比（§6）。
- 我方補充：n=50，作者估算對 |h|≥0.5 的功效約 0.70（§3.1）；Claude API 無隨機種子，不可位元級復現；目標品牌為低知名度，且注入 payload 為顯式指令，現實中的隱藏注入形式可能不同；模型版本為未來/私有型號，日後可能改變。

## 與其他研究的關係
- 支持哪些研究的結論：Nestaas 等（Adversarial SEO，ICLR 2025）指出注入可在生產系統中影響選擇——本文指出在 GPT 系列下亦然（+23~+68pp）；Greshake 等間接提示注入。
- 與哪些研究的結論矛盾：與「注入一般能推升目標」的預期相反——Claude Sonnet/Opus 下方向逆轉，其他研究（如 2606.13610）在無注入指令的內容污染中看到的是推升。
