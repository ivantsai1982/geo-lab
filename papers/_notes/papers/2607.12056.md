# 2607.12056 Designing Agent-Ready Websites for AI Web Agents: A Framework for Machine Readability, Actionability, and Decision Reliability

- 日期：2026-07
- 發表狀態：同行評審（ICEME 2026，論文首頁註明 "Accepted and presented"）
- 作者類型：學術（獨立研究者 + 大學學生；無資助，Acknowledgments）
- 一句話總結：在受控原型電商網站上，加入 JSON/JSON-LD、aria-label/data-*、證據與時間欄位後，三個瀏覽器 agent 的嚴格成功率從 49.3% 升至 89.3%。

## 研究問題
RQ1 何種網站特徵代表對 AI agent 友好；RQ2 agent-ready 設計對瀏覽器 agent 表現的影響；RQ3 哪類任務受益最大（§3.2）。提出三維框架：agent interpretability（機器可讀＋語義清晰）、executability（可操作性）、decision reliability（證據與時間有效性）（§4）。

## 研究設計
- 系統類型：受控原型網站 + 開源 browser-use 框架（非真實商業引擎；接近 agent 操作場景）
- 涉及的引擎和模型：GPT-4.1、Gemini-2.5 Flash、Grok-4 Fast；temperature 0、top_p 1；每回合上限 30 步、3 次錯誤（§5.2）。測試日期未註明。
- 樣本：5 任務 × 3 模型 × 2 網站 × 10 次 = 300 次（各 150）（§5.2）
- 對照設計：同一目錄、價格、庫存、結帖流程；僅 B 版加入框架特徵（Table 1：JSON 檔和 JSON-LD、aria-label/data-*、動作屬性、證據檔/時間欄位）。每次重啟服務器、用臨時 profile。
- 評估方式：兩名標註者人工判 PASS/PARTIAL/FAIL；另記錄步數和 token（§5.3）。未報告標註者一致性。
- 證據等級：D（可複現、受控，但為單一合成網站、非商業引擎；無真實檢索）——若嚴格對照定義可視為 D/E 之間，以 D 標註

## 主要發現
1. 嚴格成功 134/150（89.3%）vs 74/150（49.3%）；卡方 χ²(2,N=300)=60.79, p<0.001, Cramér's V=0.45（§6.1，Table 2）。
2. 各模型嚴格成功：GPT-4.1 86% vs 32%；Gemini 88% vs 52%；Grok 94% vs 64%（Table 2）。
3. PARTIAL 由 43 降至 3；功能成功 91.3% vs 78%（Table 2, §8）。
4. 任務層面 PASS：Task2 23.3%→100%、Task3 16.7%→93.3%（均 p<0.001）、Task1 73.3%→96.7%（p=0.026）；Task4 60.0%→76.7%（p=0.267）、Task5 73.3%→80.0%（p=0.761）皆不顯著（Table 3）。
5. 平均步數 9.31→6.49（-30.4%）；prompt token 降幅 Gemini 18.72%、Grok 40.47%、GPT-4.1 37.43%（§6.4，Table 4）。
6. 錯誤未消除：剩餘失敗多為推理、選擇策略或最終解釋錯誤，即使資訊齊備（§7.3）。

## 對應原理和管線階段
- 原理編號：[8, 5]。8：agent 實際讀取和操作網站，網站結構影響成功率；5：結構化可抽取資料。
- 管線階段：抓取/索引（機器可讀）、生成（agent 決策）、用戶行為/商業（電商代理採購）
- 新原理候選：「agent 就緒度」作為獨立於 SEO/GEO 的網站屬性——含可執行性（action cue）與決策可靠性（時間戳、證據）。原理 8 可細化為 interpretability / executability / reliability 三維。

## 對實踐的含義
- 有實驗支持的做法：在該原型中，整包特徵（JSON/JSON-LD + 語義標籤 + 動作屬性 + 證據/時間欄位）提升多屬性抽取、比較和選擇任務的成功率並降低步數。
- 作者建議但未經驗證的做法：MCP/API 服務、sitemap、第三方認證等（§4）未被單獨測試。
- 被證明無效或有害的做法：無；簡單政策檢索（Task 5）與多約束選擇（Task 4）差異不顯著。

## 局限與效度威脅
- 作者自述為概念驗證，不宜泛化到其他領域/網站/agent（§9）；無 ablation，無法知道哪個特徵起作用（§9）。
- B 版是同時加入多項特徵的整包處理，因果歸因不清；網站為自建原型，B 版可能與任務設計貼合（推論，非論文所述）。
- 每格 N 小（每任務每網站 30 次），Task 4/5 不顯著；標註者一致性未報告。
- 主要為 browser-use 的 DOM/文本模式，結果是否適用於視覺型 agent 未知。
