# 2607.13304 Where Does the Noise Come From? A Variance-Components Decomposition of Non-Determinism in LLM Brand Answers

- 日期：2026-07
- 發表狀態：預印本（arXiv cs.IR；v1，bootstrap 置信區間留待 v2）
- 作者類型：GEO 或 AI 可見度服務商（作者隸屬 Rankfor.AI；聲明該分配規則用於其自身測量產品的規模設計）
- 一句話總結：用可推廣性理論（交叉隨機效應）分解 LLM 品牌回答的方差，發現查詢語言是最大的系統性因素，單次回答幾乎不含品牌區分信號，增加重複次數不如增加語言和模型。

## 研究問題
品牌分數的波動有四個來源：同一提示重複採樣、提示改寫、模型、查詢語言。各占多少？在固定查詢預算下如何分配重複、改寫、模型和語言數？

## 研究設計
- 系統類型：真實商業引擎 API + 統計模型推算（決策研究部分）
- 涉及的引擎和模型，以及測試日期：GPT-5.2 與 Gemini 3 Flash（參數模式，不聯網）、Perplexity（聯網），溫度 0.3；2026 年春季單一窗口（§3.1）
- 樣本：20 個 CEE 品牌 x 8 種語言 x 3 模型 x 15 個提示；12,933 條可用回答（設計 12,960，99.8%）；其中 Category D 的 1,435 個單元重複約 5 次共 7,173 條，用於分離純重複採樣（§3.1、Table 1）
- 對照設計：三個嵌套 REML 模型：M1 主效應（全語料）、M2 加單元項（分離重複採樣）、M3 加品牌 x 面向交互（供決策研究）（§4.1）
- 評估方式：結果變數為每條回答對品牌的情緒極性（XLM-R），91.9% 正好中性，中位數 0，均值 -0.0205；不是推薦或排名指標；高斯混合模型為一階近似（§3.1、§7）
- 證據等級：B（真實商業引擎、多語言多模型、有重複採樣；但結果變數為情緒，決策研究是基於擬合分量的模型推算，該部分接近 E）

## 主要發現（逐條列出，附數字和出處節號）
1. M1：單條回答方差中，查詢語言 26.5%、模型 1.6%、品牌 1.5%（ICC 0.0146）、提示 1.1%、殘差 69.3%（§5.1、Table 2）。單次回答幾乎沒有區分品牌的信號。
2. M2（Category D 子集）：純重複採樣 34.8%、查詢語言 32.0%、品牌 x 語言 x 模型 x 提示單元交互 29.6%、模型 1.7%、品牌 1.6%、提示 0.3%（§5.2、Table 3）。「M1 殘差約分為 30 點交互與 35 點重複」推廣到全語料是假設。
3. M3：品牌脫離情境的真實分數 0.7%；唯一明顯的品牌 x 面向交互是品牌 x 語言 8.6%（作者稱「雙語懲罰」）；品牌 x 模型與品牌 x 提示約 0%（§5.3、Table 4）。
4. 決策研究（以 1 語言 x 1 模型 x 5 改寫 x 5 重複 = 25 條查詢為基礎，相對誤差方差 0.006163）：再加 5 次重複僅降 0.00030；加 5 個改寫降 0.00125；加 2 個模型降 0.00167；加 3 個語言降 0.00462（約為重複的 15 倍）（§5.3、Table 5）。
5. 可靠性上限低：單條回答排名可靠度 E(rho²) ≈ 0.01；8 語言 x 3 模型 x 15 改寫 x 1 重複（360 條）達 0.347，加到 20 次重複（7,200 條）僅 0.365；絕對分數可靠度 Phi 約 0.10（Table 6）。360 條的廣度設計優於 600 條的深度設計（0.347 對 0.332）。
6. 作者主張：優先語言，其次模型和改寫，第五次以後的重複最不划算（§5.3）。此結論來自擬合分量的推算，並未直接測試各預算方案。

## 對應原理和管線階段
- 原理編號：[7]。7（可見度是隨機分佈；如何測量）；提示改寫作為變異源與原理 2 僅間接相關
- 管線階段：生成/引用；測量（跨階段）
- 新原理候選：測量設計原理：測量誤差分為多個獨立面向，樣本預算應以廣度（語言、模型、改寫）而非深度（同一提示重複）分配。

## 對實踐的含義
- 有實驗支持的做法：在本語料的情緒結果上，跨語言和跨模型擴展比增加重複更能降低誤差（§5.3，模型推算）。
- 作者建議但未經驗證的做法：對推薦指標同樣適用（作者預期；推薦指標重新擬合列為未來工作，§5.4）。
- 被證明無效或有害的做法：在單一提示與語言上大量重複（20 次重複僅 E(rho²) 0.020，Table 6）。此結論僅限本語料的情緒結果。

## 局限與效度威脅
- 置信區間（cluster bootstrap，重採樣 20 個品牌）尚未計算，全為點估計；M2 殘差的無模型交叉驗證也尚未公布（§5.4、§7）。
- 結果變數 91.9% 為中性，非推薦；品牌信號小，導致可靠性上限低；作者預期推薦結果的品牌信號更大（推測）。
- 溫度 0.3 壓低重複採樣，34.8% 是下限；重複的邊際價值不能直接推廣到預設溫度。
- 模型面向混淆「模型身份」與「聯網模式」（兩個參數模式、一個聯網）；僅 3 個模型、8 種語言、20 個品牌，方差分量自由度少。
- 單一語料、單一窗口；兩個次要語料（六家大型企業、V-ZUG）未擬合。
- 作者有商業利益。

## 與其他研究的關係
- 支持哪些研究的結論：業界對引用不穩定的測量（Indig：三次重複僅 2.2% 來源相同；Graphite：穩定估計需 7 到 135 次運行，經本文轉引，未經本文驗證）；與 2606.23165 一致：語言影響大。
