# 2607.27686 Evaluating and Pricing Advertisements in AI-Generated Responses

- 日期：2026-07
- 發表狀態：預印本（arXiv cs.AI，未註明會議）
- 作者類型：學術（CMU、清華）
- 一句話總結：用 Big Five 人格代理模擬產生點擊意圖（CTI）標籤，蒸餾成可微分評估器（Qwen3-4B＋LoRA），再據此推導 best-of-k 廣告分配的真實出價（truthful）支付規則。

## 研究問題
LLM 原生廣告沒有點擊日誌、人工標註無法校準、零樣本 LLM 評判只反映語言流暢度；如何得到連續、可微、可用於定價與生成優化的點擊意圖信號？

## 研究設計
- 系統類型：模擬或理論（合成標籤＋訓練評估器＋機制設計）；不涉及真實搜索引擎
- 涉及的引擎和模型，以及測試日期：評估器為凍結 Qwen3-4B＋rank-16 LoRA；基線為零樣本 Qwen3.6-35B-A3B、Claude Sonnet 4.6、GPT-5.5；候選廣告由 Qwen3.6-35B-A3B 生成（§4.1、§4.4）；未標測試日期
- 樣本：NaiAD 58,999 條含廣告回答；留出集 n=5,837；擾動測試共 80 個構造項目；泛化測試 103 個虛構產品類別（訓練語料 1,348 個產品名）；人工配對 5 位標註者×100 對（§4.1、§4.3、§4.4）
- 對照設計：與三個零樣本前沿 LLM 評判在兩個核心擾動測試上對比（§4.3）
- 評估方式：客觀指標（Pearson、方向性通過率）＋小規模人工配對驗證；Q4 訓練標籤本身是 LLM 代理模擬產生，非真實點擊
- 證據等級：E（合成標籤、LLM 代理、理論機制設計）

## 主要發現（逐條列出，附數字和出處節號）
1. 留出集擬合（n=5,837）：Pearson Q1（相關性）0.85、Q2（連貫）0.73、Q3（廣告效果）0.55、Q4(CTI) 0.82（表 1）。Q4 是對合成代理標籤的擬合，不是對真實點擊。
2. 跨類別替換測試：訓練評估器在 79%（11/14，一對平手排除）的情況正確降低分數；同骨幹零樣本 33%、Sonnet 4.6 67%、GPT-5.5 60%（§4.3 第1點，圖 2b）。樣本很小。
3. 內容退化劑量反應：隨廣告被中性填充替換比例上升，預測 CTI 由 1.47 單調降至 1.14；零樣本評判在第一級退化即塌到最小值（§4.3 第2點）。
4. 虛構產品泛化：103/103 個類別中相關放置分數高於不相關（均值 3.70 vs 1.26，均差 2.44）（§4.3 第6點）。
5. 關鍵詞堆砌使分數下降；分位數校準中真實標籤均值由 0.79 遞增至 2.39（§4.3 第3、4點）。
6. 人工配對：多數人偏好與評估器一致 92%，個別標註者平均 86%，Fleiss κ=0.64；評分差>1.5 時達 96%（§4.4）。100 對、5 人。
7. 提示 LLM 扮演人格對數值輸出幾乎無影響（分數變化 |r|<0.12），人格只改變文字（§3，初步實驗）。
8. 定價：單參數機制滿足 TIE 當且僅當分配 x(v) 單調不減（定理 A.2）；以 best-of-k 構造單調分配，支付 p(v)=v·x(v)−∫x(t)dt，每點擊價 π(v)=v−(1/x(v))∫x（式 4–6）。示例 k=30 時 x=0.689、p=0.398、π=0.579（表 2）；作者說明此為結構示範，非營收預測，分數未校準到真實 CTR（§5）。

## 對應原理和管線階段
- 原理編號：[10]（AI 搜索的商業化與廣告定價）；輕度關聯 9（廣告是優化通道）。
- 管線階段：生成/引用、用戶行為/商業
- 新原理候選：無。

## 對實踐的含義
- 有實驗支持的做法：在該評估器內，放置與查詢的相關性主導分數；關鍵詞堆砌與過度呼籲行動降分（§4.3，僅為評估器行為，非真實用戶）。
- 作者建議但未經驗證的做法：以評估器可微信號訓練廣告生成；用 best-of-k 定價；對非單調分配使用 ironing 或 ε-IC（§5、§6，未實驗）。
- 被證明無效或有害的做法：零樣本 LLM 評判用於 CTI 對退化不敏感（§4.3）。

## 局限與效度威脅
- 作者承認：代理標籤尚未在大規模獨立人工基準上驗證；分數為序數代理而非校準 CTR；人格先驗證據強度不均（§6）。
- 相關性閘門是作者設計的先驗，因此「評估器重視相關性」有循環風險；擾動測試方向由作者預設。
- 評估器對真實用戶行為未驗證；人工驗證僅 100 對、5 人。
- 基線比較的樣本小（14 對跨類別交換），正文未見重複或顯著性檢驗。

## 與其他研究的關係
