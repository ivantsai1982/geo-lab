# 2608.08395 From Product Search to Preference Articulation: The Economics of Agentic Commerce

- 日期：2026-08
- 發表狀態：預印本（arXiv econ.TH，未註明期刊）
- 作者類型：學術（華盛頓大學聖路易斯 Olin、康乃狄克大學商學院）
- 一句話總結：純理論模型：偏好複雜度上升時手動搜索終將崩潰，而 Agent 搜索把稀缺性從「商品檢視」轉到「偏好表述」，並導出平台與消費者的採用落差及「反向」保真度分配。

## 研究問題
Agent 搜索如何把偏好複雜度的負擔從商品發現轉移到偏好表述？平台營收排序何時與消費者自願使用決策分歧？平台如何按注意力預算設計 AI 保真度？

## 研究設計
- 系統類型：模擬或理論（k 維單位球空間的解析模型；Lancasterian 特徵空間）
- 涉及的引擎和模型，以及測試日期：無真實引擎；Amazon、Walmart、Google、OpenAI 等僅為背景（§1）
- 樣本：無實驗；僅有參數化數值圖示（圖 4、5、6）
- 對照設計：手動搜索（有限範圍、完美保真）對比 Agent 搜索（全目錄、含高斯噪聲表述）（§3.2–3.3）
- 評估方式：解析證明（定理與命題）
- 證據等級：E（純理論）

## 主要發現（逐條列出，附數字和出處節號）
1. 手動搜索「複雜度崩潰」：存在有限的複雜度截止值，之後檢視數為零、失配回到無搜索水平（=1）、平台營收為零（定理 1，§4）。
2. Agent 搜索「複雜度衰減」：複雜度提高精煉的邊際價值，一旦開始精煉，更高複雜度下仍會精煉；失配可能上升但低於無搜索基準，營收保持為正（定理 2，§5）。
3. 採用落差：當手動檢視成本足夠低時，平台營收在較低的複雜度就偏好 Agent 搜索，而消費者（承擔搜索支出）在較高複雜度才自願採用；中間區間即使 Agent 能帶來更高營收，消費者仍手動搜索，且區間隨手動成本降低而變寬（定理 3，§6）。
4. 反向保真度分配：平台對注意力預算大的群體分配較低（弱）保真度，因其可用額外精煉補償噪聲，雖然該群體弱意義上更有利可圖；嚴格成立需三個條件（互動摩擦低、可行噪聲範圍足夠大、精度成本居中）（命題 3、4，§7）。
5. 關鍵建模假設：精煉是「重新縮放」（Assumption 1）、Agent 與消費者完全對齊、噪聲均值為零、產品均勻分佈於單位球、消費者初始相同（§3.4、§3.7）。手動失配 d=(1/k)·Beta(1/k, m+1)（Lemma 2），Agent 失配 R(T)·Dk(σ)（Lemma 1）。
6. 背景調查數字（引自他人，非本文實驗）：Adobe 報告 2025 年初 39% 美國消費者曾用生成式 AI 購物；Worldpay 44% 願讓 AI 助手代為瀏覽、僅 6% 願完全交出購買控制；Contentsquare 30% 願讓 AI 完成購買（§1）。

## 對應原理和管線階段
- 原理編號：[8, 10]。8：Agent 代為搜索與購買，用戶偏好表述決定效果；10：採用與營收分配的經濟學。
- 管線階段：用戶行為/商業
- 新原理候選：「偏好表述成本」——Agent 搜索的瓶頸從商品檢視轉為用戶表述偏好的意願與能力（理論預測，未經實證）。

## 對實踐的含義
- 有實驗支持的做法：無（無實證）。
- 作者建議但未經驗證的做法：平台評估 Agent 搜索時應計入消費者互動負擔而非只看轉化提升；高複雜度且逐品檢視成本高的品類是 Agent 搜索的自然場景；可依注意力預算差異化保真度（§8）。
- 被證明無效或有害的做法：無。

## 局限與效度威脅
- 純理論，函數形式（均勻球、高斯噪聲、對數凸 R(T)）為假設；作者稱需要經驗工作測量偏好複雜度、噪聲與互動摩擦（§8）。
- 只比較純手動與純 Agent，不含混合模式；Agent 完全對齊，排除廣告、操縱、位置偏誤；不含平台競爭（§3.1、§3.7、§8）。
- 保真度結果以參與為條件，未決定降低到何時消費者會離開（§8）。
