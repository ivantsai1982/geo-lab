# 2609.00319 Sources of Truth: A Multi-Platform, Multilingual Audit of Citations in AI Mental Health Information Queries

- 日期：2026-08
- 發表狀態：預印本（v1.0.0，arXiv cs.CY，2026-08-31）
- 作者類型：學術（哈佛醫學院／貝斯以色列女執事醫療中心數字精神病學部；聲明無利益衝突、無專項資助）
- 一句話總結：手動審計 ChatGPT、Perplexity、Google AI Overview 三個免費消費者產品對心理健康問題的引用，發現引用高度集中於少數機構來源，平台間來源類型偏好不同，要求「列出來源」幾乎不改變結果，非英語查詢的引用更少且本地化更差。

## 研究問題
1. 引用了哪些類型的來源（自建九類分類）？2. 平台間引用行為差異？3. 在提問中要求列出來源是否改變引用？4. 不同語言環境下引用如何不同？（§1）

## 研究設計
- 系統類型：真實商業引擎（免費、登出、預設設定的消費者產品），加附錄 S1 的 API 對照
- 涉及的引擎和模型，以及測試日期：ChatGPT（免費層，模型未披露）、Perplexity（免費層）、Google AI Overview；2026-06-25 至 07-20；API 對照於 07-23，用 gpt-5.4-mini（Responses API＋web_search）、gemini-3.5-flash（Google Search grounding）、Perplexity Sonar，作為未披露產品模型的近似（附錄 S1）
- 樣本：英語 20 個問題（8 個功能類別）×2 提示條件（原問題 / 附加 "List your Sources."）×3 平台×5 次重複；另有 6 種語言（西班牙、日、烏克蘭、印地、尼泊爾、Twi）各 3 個翻譯問題。共 1,140 個回覆（英語 600、非英語 540，各語言 90），15,942 條引用、1,713 個網域；有 83 個回覆（7.3%）無引用。API 側：76 個提示×3 模型×5 次＝1,140 個請求（§2、§3.1、附錄）。
- 對照設計：平台、語言（按 Joshi 2020 分高/中/低資源）、提示條件（有/無來源請求）、問題類別；七位標註員人工記錄引用；留一標註員 jackknife（82 個估計，中位最大偏差 0.82 個百分點）（§3.6）
- 評估方式：客觀指標為主。引用來源用規則式分類器（九類：政府/公共衛生、學術/期刊、非營利醫療系統、商業健康、非營利/倡議、百科、新聞、社交/視頻、其他），與人工編碼對照：200 個抽樣網域 Cohen's κ=0.88（標註員間）、0.89 與 0.86（標註員與分類器）（§3.3）。不評估答案內容是否正確，也未驗證連結是否可打開或是否支持說法（§4.4）。
- 證據等級：B（真實商業引擎、多問法、5 次重複、單一時間窗；但只審計引用組成，不審計答案正確性，人工手動採集）。

## 主要發現（逐條列出，附數字和出處節號）
1. 集中度：英語引用中 top-10 網域佔 43.6%（10,959 條）；來源類型：政府 22.6%、商業健康 22.6%、學術 21.6%、非營利/倡議 13.3%、非營利醫療系統 11.6%、百科 3.9%、社交/視頻 3.0%、新聞 0.7%（§3.3）。（正文 §3.1 寫英語 10,972 條，§3.3 寫 10,959 條，兩處數字不一致；結論處為 15,929 條已分類。）
2. 引用量：中位數三平台都在 10–12；ChatGPT 平均 32.29（SD 60.50），Google AIO 12.85（SD 6.63），Perplexity 9.7（SD 1.69）；差距由少數 ChatGPT 離群回覆造成，前 10 大的回覆都是 ChatGPT 的藥物或治療指南題（§3.2）。無引用回覆：ChatGPT 14.5%、Google AIO 7.1%、Perplexity 0.3%（§3.1）。
3. 平台來源偏好不同：ChatGPT 首位為政府（26.4%）、Wikipedia 6.1%（其他 ≤0.5%）；Perplexity 首位為學術（24.3%）；Google AIO 首位為商業健康（25.7%），社交/視頻 8.2%（多為 YouTube 7.7%）（§3.3）。問題類別也影響：治療效果題學術 56.9%；危機資源題非營利/倡議 41.6%；藥物題商業健康 33.7%（§3.3）。
4. 要求「列出來源」作用很小：英語平均 16.6→19.9 條；主要由 ChatGPT（27.3→37.2）造成；Perplexity 9.2→10.3，Google AIO 13.4→12.3；來源類型變化最多 2.1 個百分點，方向為更偏政府（+2.1）、商業健康（+1.6）、學術（+0.8）（§3.4）。
5. 非英語：平均引用 9.2 vs 英語 12.3（同 3 題），Spanish 11.2 到 Twi 7.1；ChatGPT 英語 17.5 條 vs Twi 4.3 條，且 Twi 33%、日語 23% 的回覆無引用；Google AIO 印地語 30% 無引用；Perplexity 在 8.6–10.2 之間穩定（§3.5）。按 ccTLD 衡量的「本地」份額：高資源語言 38.0%、中 20.8%、低 3.3%；計入母語頁面後 Twi 2.5%→37.6%、西班牙語 11.3%→46.2%（西班牙語多被導向 medlineplus.gov/spanish 等美國政府頁面）（§3.5）。作者認為本地化取決於權威母語內容的供給，而不是語言資源等級，這是解釋性推論（§4.1）。
5b. 標註員均在美國，IP 可能影響國際連結/本地化連結量（§4.4）。
6. API 對照（附錄 S1，補充分析）：API 每回覆 9.4 條 vs 產品 14.0；無引用回覆 API 19.8% vs 產品 7.3%，主要由 gpt-5.4-mini 造成——它只在 50.3% 的請求中調用 web search，且沒有搜索的回答依然正文完整（>1,300 字）；gpt-5.4-mini 全部僅引 31 個網域，英語 top-10 佔 97.4%，而 ChatGPT 產品為 52.0%（641 個網域）；其政府來源佔 70.6%（產品 26.4%）且完全不引商業健康、百科、社交（表 A1、A2）。
7. API 下「列出來源」的效果大得多：gpt-5.4-mini 調用搜索的比例由 12.1% 升至 88.4%（英語 19.0%→99.0%），每回覆引用 0.60→7.05；政府來源份額 +11.6 個百分點；gemini-3.5-flash 由 81.1%→95.3%（附錄 S1）。作者解釋這主要是「是否檢索」的切換，而不是來源選擇變化。
8. 詞彙鄰近異常：問抗焦慮藥物被導向 Wikipedia 的「蛋黃醬」條目（與 Mayo Clinic 連結並列）；「DSM」被導到 DSM-Firmenich 與 Synology DSM；PCL-5 被導向建築公司；印地語抑鬱症診斷被導向百老匯 Hamilton 門票（§4.2）。作者沒有發現詞彙鄰居提供誤導性健康內容，但推測攻擊者可能佔領詞彙相鄰網域（未驗證，只是設想）。

## 對應原理和管線階段
- 原理編號：[1, 3, 4, 7]。1：API 側顯示「是否觸發搜索」對提示措辭很敏感；3：語義/詞彙匹配影響召回，第三方與機構來源、母語內容供給決定本地化；7：平台引用量差異大、ChatGPT 引用量長尾；4 只在集中度層面相關。
- 管線階段：觸發、檢索、生成/引用
- 新原理候選：不在現有原理內的機制較少。可考慮的：「提示措辭（如要求列出來源）改變是否觸發檢索」——這是 API 側證據（gpt-5.4-mini 12.1%→88.4%），產品側影響很小，因此該機制的普遍性有限，需在更多產品上驗證。

## 對實踐的含義
- 有實驗支持的做法：在提示中加「列出來源」對消費者產品的引用量與組成影響很小（英語平均 +3.3 條、組成 ≤2.1 個百分點）；但對 API 模型調用檢索的機率影響很大。
- 作者建議但未經驗證的做法：對公衛機構與 AI 公司投資多語言權威內容；定期做產品級引用審計；以數字素養與監管作為補充（§4.3、Conclusion）。
- 被證明無效或有害的做法：用戶自己加「列出來源」在產品側基本無效（作者的表述，數據支持其為小效應，非零）。

## 局限與效度威脅
- 單一時間點（2026 年 6–7 月）；只審計免費、登出的層級；具體模型版本不可得。
- 只審計引用組成，不審計答案正確性；連結有效性僅檢查語法，未驗證能否打開或是否支持說法（§4.4）。
- 非英語只有 3 題，且標註員都在美國；問題集由研究者設計（20 個一般性心理教育問題）。
- 手動記錄引用，可能有記錄誤差，但有 jackknife（ChatGPT 平均引用 24.1–38.9、無引用率 8.2–17.1% 兩項最不穩定）。
- 來源類型分類器是規則式，網域級判斷，一個網域內頁面質量差異被忽略。
- API 對照的模型並非產品實際使用的模型（作者強調這是近似）。
- 數字有輕微不一致（英語 10,972 vs 10,959 條）。
