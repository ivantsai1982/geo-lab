# 2609.02316 Counter-GEO-Bench: Evaluating Defenses Against Information-Distorting Generative Engine Optimization

- 日期：2026-09
- 發表狀態：預印本（未註明；arXiv v1，2026-09-02）
- 作者類型：學術（清華深圳、港大）
- 一句話總結：建立首個針對「夾帶虛假主張的 GEO 改寫」的防禦基準（247 條人工核驗查詢，配對「保真 IP」與「扭曲 ID」改寫），發現三種現成護欄幾乎無效，而 184M 參數的對比式分塊偵測器 C-GEO Guard 可把攻擊成功率相對降低 47.6%。

## 研究問題
攻擊者發布看似普通、GEO 優化過的網頁並嵌入指定虛假主張，受害 LLM 檢索後是否會把它寫入答案？現成護欄（安全分類、事實核查）能否防禦？（§1、§3）

## 研究設計
- 系統類型：可複現 RAG 管線（自建 harness：512 token 分塊、BM25+BGE-large 0.3/0.7 混合召回 top-50、BGE cross-encoder 重排至 top-12、引用強制的生成）
- 涉及的引擎和模型，以及測試日期：受害 LLM 為 Gemma-4-31B-IT、Qwen-3.5-35B-A3B、Llama-4-Scout-17B-16E（vLLM，溫度 0）；改寫器 Claude Sonnet 4.6（另以 GPT 5.5 做跨改寫器測試）；判官 Claude Opus 4.6。無真實商業引擎；未註明測試日期。
- 樣本：自 GEO-Bench 測試集 1,000 個查詢-來源對出發，經品質閘（Q >= 0.65）保留 250，人工核驗剔除 3 個，得 247 條（Table 1、§3.2）。每條含 clean / IP（保真 GEO）/ ID（扭曲 GEO）三個版本，其餘 4 個來源不變；ID 改寫把權威域名（Wikipedia/.gov/.edu）改成部落格/評論站風格。
- 對照設計：clean vs IP vs ID 的配對設計；未防禦 vs 四種防禦（Granite Guardian 3.3-8B、Llama Guard 3-8B、NeMo Self-Check Fact-Checking、C-GEO Guard）
- 評估方式：LLM 評判（ASR 三值 1.0/0.5/0.0）；有人工驗證：Opus 與兩位標註者 kappa = 0.739 / 0.869（每模型 50 例分層樣本，§5.1）；配對 bootstrap 顯著性檢定
- 證據等級：E（固定/自建管線，虛假主張與改寫皆由 LLM 生成，LLM 評判）

## 主要發現（逐條列出，附數字和出處節號）
1. 未防禦時三模型平均 ASR = 55.7%（95% CI [53.1, 58.2]）（§5.2、Table 3）；各模型 56.5 / 55.9 / 54.7。
2. 現成護欄幾乎無效：Granite Guardian 平均 ASR 降 1.7pp（不顯著，p=0.096）；Llama Guard 3 降 3.2pp（顯著，相對 -5.7%）；NeMo Self-Check 在 Qwen 上僅攔截 3.24% ID 輸出卻拒答 4.86% clean 輸出，在 Llama-4 上拒答 98.4% clean（Table 3、§5.2）。
2b. 分塊層面：Granite / Llama Guard 對 ID 分塊僅攔 0.61% / 0.83%，與 clean 攔截率 0.43% / 0.65% 幾乎無差異（Table 4）。
3. C-GEO Guard（DeBERTa-v3-base，184M，MNRL 對比訓練 + 類別原型質心）ASR 55.7% 降至 29.2%，相對 -47.6%（絕對 26.5pp；CI [23.8, 29.3]）；ID 分塊攔截 10.27% vs clean 2.30%；答案品質 4.48 vs 4.49（Table 3、Table 4）。
4. 跨改寫器遷移：GPT 5.5 改寫（Qwen 受害，無品質閘）ASR 55.7% 降至 22.1%（相對 -60.4%），IP 準確率 86.8 降至 82.6（§5.4、Table 6）；獨立撰寫模板下相對降幅降為 32.0%（Table 7）。
5. 「防禦放大攻擊」：Llama-4 上 Granite Guardian 使 74 個查詢惡化、57 個改善；作者解釋為移除與虛假主張矛盾的 clean 分塊消除了跨來源分歧（§6.2；解釋為推測）。
6. 僅 17.2% 的查詢在三個受害模型上都完全成功，55.2% 存在模型分歧（§6.2）。
7. 被誤導的答案品質較低（ASR=1.0 時 4.29 vs ASR=0.0 時 4.70）；作者推測因承諾錯誤主張而壓縮回答，屬推測（§6.3）。
8. 品質閘通過率：IP 59.7%、ID 26.9%、聯合 25.0%（Table 1）。

## 對應原理和管線階段
- 原理編號：[9, 4, 6]。9：優化與操縱走同一通道，既有護欄防不住；4：進入上下文後的內容如何影響答案；6：被引用/被吸收的內容不保證正確。
- 管線階段：重排/上下文、生成/引用、吸收/保真
- 新原理候選：「多來源分歧是隱性防禦」——過濾對立的乾淨來源會放大虛假主張（§6.2，於 Llama-4 + Granite 的觀察，證據有限）。

## 對實踐的含義
- 有實驗支持的做法：針對 GEO 操縱模式訓練的輕量分塊偵測器（用 IP 作硬負例）可降低 ASR 而不損失答案品質（僅在此基準上）。
- 作者建議但未經驗證的做法：跨來源分歧量化、外部事實核查、來源溯源過濾（§7）。
- 被證明無效或有害的做法：以安全分類法護欄（Granite Guardian、Llama Guard）過濾此類內容；NeMo 自檢式事實核查（同模型自判）誤傷 clean 內容且與攻擊無關聯；過濾可能反而放大攻擊。

## 局限與效度威脅
- 作者自述：247 條英文查詢；單文檔攻擊；僅三個開放權重模型，未含商業 API 或整合產品；未研究偵測器感知的自適應攻擊（人工編輯、風格遷移）與開放集攻擊（Limitations）。
- 虛假主張、改寫、評分準則皆由 LLM 生成，且 ID 模板要求虛假主張至少重複三處；品質閘只保留 25% 樣本，可能偏向特定模板；C-GEO Guard 訓練與測試同源（同一改寫器、同一模板），遷移實驗才部分緩解。
- 判官為 Claude Opus、改寫器為 Claude Sonnet，同家族可能存在偏差（此為讀者推測）。

## 與其他研究的關係
- 支持哪些研究的結論：Chen 等（2026）「傳統黑帽 SEO 在檢索層被擋而 LLM 導向策略仍能到達摘要層」；PoisonedRAG 一類研究。
- 與哪些研究的結論矛盾：無直接矛盾；與 2609.02964 互補（後者針對事實保真的 GEO，本文針對含虛假主張的 GEO），兩者一致顯示通用防禦（PPL、安全提示、安全護欄）效果差。
