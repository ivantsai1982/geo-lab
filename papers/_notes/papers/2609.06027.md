# 2609.06027 Evaluating Deep-Search Agents under Hierarchical Web Evidence Poisoning

- 日期：2026-09
- 發表狀態：預印本（未註明；arXiv v2，2026-09-17，cs.CR）
- 作者類型：混合（浙江大學、螞蟻集團）
- 一句話總結：HAE-GEO 基準讓 10 個搜索代理在「同一虛構品牌與虛假主張、三級遞增說服力（直接斷言 / 情境偽裝 / 表面佐證）」的網頁投毒環境中多輪搜索，發現佐證式投毒使證據辨識下降，且驗證很少轉化為糾正。

## 研究問題
現有基準只看被投毒內容是否被檢索或背書，沒有追蹤代理是否驗證可疑證據、修正已採納的說法、最終是否恢復。隨投毒說服力升級，代理在「暴露 -> 採納 -> 驗證 -> 背書 -> 恢復」各階段表現如何？（§1）

## 研究設計
- 系統類型：可複現受控環境中的搜索代理（自建 Search / Scrape 介面，非真實商業引擎）
- 涉及的引擎和模型，以及測試日期：10 個代理：Claude-Opus-4.8、GPT-5.6-sol、Kimi-K3、GLM-5.2、GLM-4.7-Flash、MiniMax-M3、Qwen3.8-27B、Qwen3.6-35B-A3B、Qwen3.5-397B-A17B、DeepSeek-V4-Flash；毒頁由 Claude-sonnet-4.6 生成；評判為 GPT-5.5（兩個隔離評判）；未註明測試日期（事件引用為 2026-03）
- 樣本：乾淨語料 72,039 個真實網頁；每級 770 個毒頁（預算相同）；8 個品類、154 個品牌、8 種頁面類型；1,011 個查詢池中固定取類別均衡的 120 查詢；每模型 x 2 種提示（BASE / DEF 防禦提示）x 4 個環境（Clean/L1/L2/L3）；最多 10 輪決策（§4.1、Table 3）
- 對照設計：Clean 與 L1/L2/L3 配對環境；BASE vs 投毒感知 DEF 提示；Agentic Search-Scrape vs Static Full-Context（僅 Kimi-K3、Qwen3.8-27B）；推理開/關（同兩個模型）
- 評估方式：確定性行為指標（暴露條件下被騙率 FR、嚴格驗證收益 SVY、驗證到恢復 V2R）+ 六維 0–2 分 rubric（M1–M6）由 LLM 評判；未見評判人工驗證
- 證據等級：E（合成/受控語料與虛構品牌、LLM 評判；有多模型、多級別、配對對照，但非真實引擎與真實用戶）

## 主要發現（逐條列出，附數字和出處節號）
1. 「佐證陷阱」：宏平均 M1（風險處理）L1 到 L3 由 0.83 降至 0.30（BASE）；M2（毒證辨識）由 1.02 降至 0.33（BASE）；DEF 下 M1 降 0.65、M2 降 0.51（§5.2、Figure 3）。作者強調個別模型有反轉，L1–L3 並非對每個模型都單調。
2. 防禦提示（DEF）提高 M1、M2，但對最終背書的影響因模型而異：Kimi-K3 DEF 的 FR 為 10.9 / 24.2 / 18.8%（L1–L3）；GPT-5.6-sol 的 L1 FR 不變為 33.3%，L2 由 47.6 到 49.2%；GLM-4.7-Flash 在三級都高於 46%（Table 5）。Base 下 FR 最高的是 Qwen3.6-35B（L3 69.4%）與 GLM-4.7-Flash（L3 65.1%）。所有 10 個模型在 DEF 下的攻擊情境效用（M6）下降 0.01–0.27（§5.2）。
3. 代理式搜索優於單次全上下文檢索的最終抵抗：FR 降幅（Static − Agentic）為 Kimi-K3 Base +13.6pp、Defense +16.0pp，Qwen3.8-27B Base +42.7pp、Defense +35.4pp；但 M2 變化小且信賴區間常包含 0，M6 多為持平或下降（§5.3、Figure 4）。
4. 驗證不等於恢復：嚴格驗證收益 SVY 在 DEF 下由約 2% 升到約 17%（L1/L2/L3 為 17.1/17.1/17.2%），最終背書率卻由 28.6% 升到 36.3%、38.6%（Base 為 43.3/47.9/51.0%）（§5.4、Figure 5）。
5. 驗證到恢復 V2R（DEF）由 L1 的 81.8% 降至 L2、L3 的 66.7%，但符合條件的軌跡僅 11 / 9 / 3 條，作者稱不能做強因果宣稱（§5.4）。
6. 明確推理有幫助：Kimi-K3 FR 降 9.7（Base）/ 8.8（DEF）點；Qwen3.8-27B 降 16.0 / 19.8 點；M1、M2 亦上升（Table 6；僅兩個模型）。
7. 成本：DEF 平均每查詢多 1.82 次工具調用，token 宏平均增加 24.5%（GLM-5.2 +8.6% 至 Claude-Opus-4.8 +52.0%）；GLM-4.7-Flash 多花成本但 FR 仍高（Table 7、§5.6）。
8. 穩健性與效用的取捨：所有模型 DEF 後更穩健但效用降低；Kimi-K3 防禦後穩健性最高，Qwen3.6-35B 保留最高效用（§5.7、Figure 6）。

## 對應原理和管線階段
- 原理編號：[8, 6, 9]。8：Agent 實際多輪讀取網頁並據此推薦；6：被讀取/採納不等於被正確使用，驗證後仍可能背書假證據；9：零和競爭與操縱走同一通道（佐證式內容偽造）。
- 管線階段：檢索、重排/上下文、生成/引用、吸收/保真、用戶行為/商業（消費決策推薦）
- 新原理候選：「驗證行為與糾正脫鉤」——Agent 做了獨立驗證，最終推薦仍不改變（§5.4，樣本小）；「佐證陷阱」——虛假主張加上表面多源佐證比單純斷言更難被識別。可作為原理 6/8 的補充。

## 對實踐的含義
- 有實驗支持的做法：（防禦/平台側）防禦提示、明確推理（reasoning）與代理式多輪搜索可降低被騙率，但有效用與成本代價。
- 作者建議但未經驗證的做法：訓練代理判斷何時信任網頁證據並在採納後修正（§6 結論屬展望）。
- 被證明無效或有害的做法：僅靠防禦提示對部分模型（GPT-5.6-sol、GLM-4.7-Flash）效果有限；提高驗證次數並不保證糾正。（對內容經營者：偽造多源佐證在此受控環境中最能誤導代理，這屬操縱，不是可推廣的正當 GEO 做法。）

## 局限與效度威脅
- 未見獨立局限章節。讀者評述：
- 毒頁與判定全在受控語料中，虛構品牌；真實引擎的檢索排序、域名信任與去重未還原；毒頁由 LLM（Claude-sonnet-4.6）生成，評判為 GPT-5.5，且未見評判人工驗證。
- 恢復相關結論建立在極小子集（DEF 下 11/9/3 條；Base 下 2/2/2 條），M3 對 GPT-5.6-sol 不可觀測；推理與代理式對照僅在兩個模型上。
- 120 個查詢、8 個品類，僅涵蓋消費品推薦；投毒預算固定於 770 頁/級，佔語料約 1%（770 / 72,039，為讀者計算）。
- 語料僅公開部分（版權與爬取限制），影響完整復現。

## 與其他研究的關係
- 支持哪些研究的結論：FORGE、SearchGEO、SafeGEO、EcoGEO、WARP 等關於搜索代理易被網頁內容操縱的結論；並延伸至驗證與恢復階段（2606.16821 為其中之一，已在本批外）。
- 與哪些研究的結論矛盾：無明確矛盾；「更多工具使用能交叉驗證」的假設被部分否定（驗證多但恢復少）。
