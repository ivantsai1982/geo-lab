# 2609.25189 GroundedGEO: Auditing the Evidence Gap in Generative Search Rankings

- 日期：2026-09
- 發表狀態：預印本（未註明；arXiv cs.IR v1，2026-09-21）
- 作者類型：學術（深圳大學）
- 一句話總結：在受控的電商排序基準上，證明部分 LLM 排序器會獎勵「無證據支持但貼合查詢的細節」；一個以「主張—證據包」為基礎的懲罰層在使用理想標籤時能壓低這種收益，但自動標註器未通過預先註冊的可靠性門檻，且證據包覆蓋不足會誤傷誠實內容。

## 研究問題
- 文本本身無法區分「有據的詳細內容」與「捏造的詳細內容」（作者稱「可識別性缺口」）。排序器獎勵的是「未被支持的相關性」嗎？加入證據通道能否防禦，其價值受哪些條件限制？（§1、§3）

## 研究設計
- 系統類型：固定上下文 LLM／合成基準（候選集固定為 1 個目標＋4 個干擾項，只改寫目標描述）；防禦端為逐點打分後處理層。
- 涉及的引擎和模型，以及測試日期：現象測量用三個 listwise 排序器 Qwen2.5-7B（本地）、GLM-5.3-Flash、MiMo-v2.5（API）（§5.6）；防禦端基礎打分器與 API 判官為 DeepSeek-Flash（§5.3、§8）；本地判官 L1=Qwen3.6-35B-A3B-NVFP4、L2=Qwen3.8-27B-NVFP4。未註明測試日期。
- 樣本：50 條英文電商查詢（來自 ESCI），5 種變體臂（clean／supported-rich／unsupported-rich／neutral-matched／evidence-laundering），3 種主張類型輪廓，共 13 變體 x 3 種排序順序 x 50 = 1,950 個 case（§3.1）；40 查詢開發集＋10 查詢留出集；人工金標 370 條主張（10 查詢、2 名標註者）；4,250 條主張由本地判官全部標註（§5.3、§5.6）。
- 對照設計：各臂長度匹配（clean 除外）；packet twin（文本固定、僅增加證據原子）與 thinned packet（移除誠實主張的證據）互為鏡像探針；文本長度懲罰作為僅看文本的對照（§3.3、§5.4、§5.5）。
- 評估方式：客觀指標（歸一化排名增益 NRG、top-3 率、誤傷率 FSR）；標註可靠性以人工金標評估（Cohen kappa、macro-F1）；Wilcoxon 符號秩檢驗＋Holm 校正，以查詢為統計單位 n=50（§3.5、§5.5）。
- 證據等級：E（固定上下文、合成描述、合成證據包；防禦部分依賴構造標籤）

## 主要發現（逐條列出，附數字和出處節號）
1. Qwen2.5-7B 上，unsupported-rich 相對 clean 的 NRG 為 +0.065 至 +0.092（Holm 後 p 介於 0.0011 至 0.035），三種主張輪廓皆顯著；在規格（S）輪廓下甚至超過 supported-rich（+0.103，p=0.0010）。supported-rich、neutral-matched、laundering 均與 clean 無顯著差異（表 3、§6.1）。
2. 該效應依模型而異：MiMo-v2.5 只有 S 輪廓的 unsupported vs neutral 一項顯著（+0.068，p=0.037）；GLM-5.3-Flash 無任何顯著對比（表 3、§6.1）。作者明言這是「特定排序器上的易感性」，不是普遍結論。
3. 長度懲罰（0.05/0.10/0.15 每 token）無法複製證據條件抑制：0.15 時攻擊臂從 0.65/0.61 降至 0.63/0.59，誠實豐富臂同時從 0.75 降至 0.73（表 4、§6.2）。僅限該長度代理，作者不主張所有文本防禦都無效。
4. 使用理想（構造）標籤時，λ 從 0 增至 40，unsupported-rich 的 top-3 率由 0.65 降至 0.43，laundering 由 0.61 降至 0.39，clean（0.84）、supported-rich（0.75）、neutral（0.75）不變，FSR=0（表 5、§6.3）。
5. packet twin 只改證據包、文本不變，即把 λ=40 下的攻擊臂率恢復到 λ=0 水平（0.43→0.65、0.39→0.61）（表 5、§6.4）。這是「證據世界」存在的存在性證明，不是真實檢索或證書驗證的測試。
6. 三個自動判官全部未通過預先註冊門檻（macro-F1>=0.75 且 kappa>=0.60）；最佳的 L2 為 macro-F1 0.374、kappa 0.442；懲罰決策精確率 0.944、召回 0.819；API 判官召回僅 0.271。錯誤方向是「放過捏造」而非「誤殺誠實」（表 7、§6.5）。
7. 儘管未過門檻，L2 在全 1,950 case 上達到理想抑制的 79%（unsupported）和 100%（laundering），FSR=0（表 8、§6.6）。人工金標臂是唯一不利格：抑制 +0.167 而 FSR +0.300，作者說明主要來自 5 條被人工判為 unsupported 的 clean 基礎身份主張，成因（金標噪聲或標準差異）待裁定（§6.6、表 9）。
8. 證據覆蓋劑量反應：把誠實主張的證明記錄移除 0/25/50/75/100% 時，supported-rich 的 top-3 率由 0.753 降至 0.713/0.600/0.533/0.447；100% 時 FSR +0.307，接近被捏造內容的 0.427（表 10、§6.7）。
9. 標籤噪聲掃描：精確率決定誤傷（P=0.30 時 FSR 0.20–0.38；P=1.00 時 0），召回決定抑制（R=0.2 時 +0.017，R=1.0 時 +0.223）（表 11、§6.8）。
10. λ 調參規則在開發集上弱可識別（理想與 L2 都選到網格邊界 λ=160；L1 選 40），主表 λ=40 不是調優後的最優點（表 12、§6.9）。

## 對應原理和管線階段
- 原理編號：[5, 6, 9]。5：可抽取、可驗證的證據；6：被引用/被採信不等於被正確使用（證據支撐度是主張與證據的關係）；9：優化與操縱走同一通道，防禦機制的限制。
- 管線階段：重排/上下文 → 生成/引用（排序層的操縱與防禦）；間接涉及吸收/保真。
- 新原理候選：「證據可識別性缺口」——排序器只看候選文本時，無法區分有據與無據的細節；防禦需要外部證據通道，而其效果同時受標籤品質與證據覆蓋率限制（覆蓋不足會懲罰誠實的小型發布者）。

## 對實踐的含義
- 有實驗支持的做法：在受控條件下，「對無證據支持的查詢相關主張扣分」可壓低攻擊臂而不傷保護臂（前提是標籤正確且證據包完整，表 5）。
- 作者建議但未經驗證的做法：自動標註後部署為平台防禦；為被誤懲罰的發布者提供申訴／補交證明的機制；平台需按排序器逐一審計（§7.4、§9）。均未在真實系統驗證。
- 被證明無效或有害的做法：以文本長度懲罰來防止「捏造式豐富」（無選擇性，表 4）；對誠實內容而言，缺少第三方佐證記錄本身有風險（表 10）。對發布者角度：堆疊規格／用例類細節，在部分排序器（Qwen2.5-7B）上確實能提升排名，但只在小型開源排序器上顯著，不應直接外推到商業引擎。

## 局限與效度威脅
- 只有 3 個排序器，效應只在 1 個顯著；任務是 5 候選的電商排序，不是真實 AI 搜索引擎，沒有檢索或抓取環節（§8）。
- 證據包是研究者建構並隨查詢提供的；「unsupported」是封閉世界定義，非事實為假（§3.4）。攻擊文本為合成。
- 人工金標僅 10 查詢／370 主張，且與構造標籤存在未解的分歧；判官只來自同一模型家族；基礎打分器單一（DeepSeek-Flash）（§8）。
- 干擾項不帶主張，因此懲罰只作用於目標；歸一化的特殊形式限制了對多候選競爭的結論（§7.1、§8）。
- 原文自述：不是「已驗證的自動防禦」；部分主表未報告預先凍結的 Promotion reduction 主要終點（§8）。
- 摘要與正文對 λ=40 的比較不是在開發集選出的最優點。

## 與其他研究的關係
- 支持哪些研究的結論：GEO 改寫可提升可見度（Aggarwal 等 GEO）、對排序器的操縱攻擊（論文引用的 [14][15]）；與 2304.09848 同樣強調「有引用不等於有支持」，但把審計從答案端前移到排序端。
- 與哪些研究的結論矛盾：與 SCI-Defense 等基於文本表面特徵的防禦形成對比（作者聲明不主張優於它們）；無直接矛盾的實證。
