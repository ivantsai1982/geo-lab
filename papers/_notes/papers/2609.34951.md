# 2609.34951 AX is the New AEO

- 日期：2026-09
- 發表狀態：預印本（未註明）
- 作者類型：GEO 或 AI 可見度服務商（ora research；被測的「agent 就緒度評分器」是作者公司自有產品，作者自己承認「The ranker is our own」，有利益衝突）
- 一句話總結：在 1,056 家真實企業（按名氣、模型先驗知識、兩個 AEO 代理指標配對）上跑 37,927 次 agent 旅程，發現網站對 agent「可讀」（AX）決定答案由誰的內容構成、是否被明確推薦，而站外被提及（AEO 代理指標）在控制 AX 後無獨立效應。

## 研究問題
AEO/GEO 主要管「被浮現（surfacing）」；但 agent 會打開結果並多輪 search/fetch（drill-down）。在此步驟，企業自有網站能否被 agent 抓取和閱讀（AX）是否比站外被提及更決定答案內容、推薦與成本（摘要、§1）？範圍限於「讀」層，不含「找」和「操作」層（§1）。

## 研究設計
- 系統類型：真實商業/開源 agent 執行環境（harness），真實網站，實時搜索與抓取；非用戶行為
- 涉及的引擎和模型：claude-agent-sdk（claude-sonnet-4-6，Anthropic 內建搜索）、claude-code（claude-haiku-4-5）、openclaw（gpt-5.4-mini + Tavily）、eve（gpt-5.4 + Tavily）（Table 2）。ora 評分快照 2026-08-24；論文 v2 為 2026-09-29。
- 樣本：1,056 家企業（每組 528），每企業 3 個意圖提示（價格/功能/設置）× 每個 harness 3 次 = 每企業 36 次；共 37,927 次旅程（§4.2，摘要）。準確率子樣本：131 家企業、2,499 個答案、31,127 個事實（§4.3）。
- 對照設計：準實驗式配對（非隨機分配）：agent-ready（可訪問性分數 ≥0.65）vs 非（≤0.50），中間帶排除；按 log10 Tranco 排名、訓練數據存在度、引用廣度（AEO 代理）、ora discovery 分數，在同行業與名氣帶內最近鄰配對，卡尺 2.5 SD；配對後 SMD 均 <0.1（Table 1）。
- 評估方式：日誌指標（第一方證據份額、搜索次數、成本）＋ LLM 評判（答案成分歸屬；推薦強度由兩個不同廠商的評判 claude-sonnet-4-6 與 gpt-5.4，均給最高分才算明確推薦，88% 答案兩者相差在 1 分內）；準確率對照無頭瀏覽器捕獲的事實逐條打分（含半分）。評判對組別盲。未見對評判的人工驗證說明。
- 統計：以企業為單位；置換檢驗 20,000 次；bootstrap 95% CI（§4.3）。
- 證據等級：B（真實 agent 產品與真實網站，多次重複、多 harness；但為配對觀察性設計，非隨機、非真實用戶行為，且 harness 而非 ChatGPT/Perplexity 等消費端引擎）

## 主要發現
1. 模型記憶份額：同 90 個買家問題，gpt-4.1 約 52%（正文「about half」）→ gpt-5.6 14%；本研究四個 harness 中訓練知識占最終答案 7–10%，不論網站是否可讀（§3 Figure 1、§5.3）。Figure 1 為作者用 claude-sonnet-4-6 評判的測量，另引用他人數據：ChatGPT 帶當年錨點的搜索占比 6%→87%（Kaya 2026），近期問題約 9/10 觸發搜索（Kale 2025）（Figure 2，屬轉引）。
2. 答案成分：agent-ready 者 78% 來自自家頁面、12% 來自網頁搜索；非 ready 者 58%（正文另處作 56%/55.5% grounded-answer rate）、25%（Figure 7）。第一方證據份額 0.776 vs 0.549（1.41×，CI [1.36,1.47]）（Table 7）。
3. 約 99% 遇到死路的旅程 agent 仍照樣作答（§5.3）。
4. 明確推薦率 20% vs 11%（1.93×，CI [1.74,2.15]，p<0.0001）；四個 harness 均同向但基線差異巨大：claude-code 5% vs 2%，eve 36% vs 20%（Figure 5）；12 個類別全部有提升，1.2×（客服）至 2.5×（IT 基礎設施）（Table 3）。
5. 不可讀網站的答案更多「對沖」：承認無法訪問 4.4×（3.6% vs 15.9%）、依賴二手來源 3.0×、含糊 1.8×、讓用戶自己去查 1.4×（Figure 6、Table 7）。
6. 劑量反應：可訪問性分數九個分箱中，平均網頁搜索次數從 1.8 到 4.5（Spearman ρ=-0.52，n=1,056）（Figure 8）。
7. 成本：非 ready 者多 23% 回合（5.5→6.8）、被站點封鎖 2.1×、慢 15%；每個「落地於該企業」的答案成本 +64%（+93% 於兩個 stack，+11% 於 eve）（§5.4、Figure 9）。
8. 準確率（131 家、配對於同企業/harness/題型的 196 個格子）：站點構建答案 48.3% vs 網頁構建 34.3%（+41%，p<0.0001）；空答案（無任何被問事實）為 3.7×（25.0% vs 6.7%）；事實層面「說錯」僅 4%→6%，「未提及」29%→45%（Table 5、Figure 10）。價格題 +64%，功能 +18%（p=0.018），設置題 +2%（p=0.87，不顯著）。eve 上 -2.3pp、openclaw +4.0pp（p=0.051）均不顯著。
9. 重要保留：兩個分組之間的準確率差僅 51.7% vs 49.8%（p=0.52，不顯著，Table 7）；作者稱「+41%」是「讀站點 vs 不讀」的比較（agent 自選通道，作者以配對控制難度），並非「可讀組 vs 不可讀組」（§5.5）。
10. AEO 代理指標在控制 AX 後：對落地、推薦、成本的偏相關均不顯著（discovery 對推薦 r=0.10, p=0.002 未達其 p<0.001 確認線）；而可訪問性對應 +0.62、+0.41、-0.27（Table 6）。作者也說配對後兩組 AEO 的離散度仍有 92–93%，所以該檢驗有效（§5.6）。

## 對應原理和管線階段
- 原理編號：[1, 3, 6, 8, 9]。1：模型記憶占 7–10%，主要來自檢索；3：抓取（無 JS 渲染內容、bot 封鎖）與第三方來源；6：答案吸收（落地份額）與保真（省略而非編造）；8：agent 讀取站點；9：站外被提及與站內可讀之間的替代關係，以及阻擋後的競爭替代（如 HashiCorp 案例結束於兩個競爭對手博客，Figure 3，個案示例）。
- 管線階段：抓取/索引、檢索、生成/引用、吸收/保真、用戶行為/商業（推薦）
- 新原理候選：(a) 「drill-down 步驟」：SEO/AEO 管浮現，站點可讀性管答案由誰的內容構成——把可見度管線的「檢索」拆成「浮現」與「下鑽讀取」；(b) 站點不可讀時 agent 不停止而是替代（用第三方/競爭對手內容填補），失敗模式是省略而非編造；(c) 對 agent 阻擋的成本由 agent 運營方而非站點承擔。

## 對實踐的含義
- 有實驗支持（準實驗，關聯性）：無 JS 也能取到內容、結構化資料、llms.txt/Markdown 回退、價格與 API 文檔可訪問、bot 控制放行用戶觸發的 agent，這些構成的「可訪問性分數」高者，落地率、推薦率更高。但這是把分數整包比較，無法拆分具體哪項起效。
- 作者建議但未經驗證的做法：對站點做 AX 改造（本研究無干預前後實驗，§7 自承需要干預研究）；「AX 是最強槓桿」屬作者的結論性主張。
- 被證明無效或有害的做法：作者的數據顯示站外提及廣度（citation breadth）在控制 AX 後沒有獨立效應（Table 6）；但這只針對「已被該 harness 打開站點」的 drill-down 場景，且僅為兩個代理指標，不代表站外策略對浮現無效（作者自己也說 being found still matters）。

## 局限與效度威脅
- 作者自述：內容深度未配對——封鎖 agent 的站點可能也發布更少內容，會單獨擴大差距；分組層面的落地與推薦對比無法排除；準確率僅 131 家；群組間準確率差不顯著；樣本偏 SaaS/商務、英文、事實查詢類意圖（§7）。
- 處理變量（ora 評分）由作者公司開發，且分組閾值為「本研究自定」；評判為 LLM，未見人工驗證。
- 提示為「site-anchored」（明確給了域名），即 agent 已被告知去哪個站點，所以結果不能推到「無品牌名的發現階段」（推論，非論文所述；論文亦稱固定了發現層）。
- 配對觀察，不是隨機處理。harness 混合了模型與搜索供應商，不能比較組件（Table 2 說明）。
- 部分引用的行業數據（Cloudflare、Kaya、Promptwatch、Qwairy 博客等）為非同行評審來源。

## 與其他研究的關係
- 支持哪些研究的結論：與 2607.12056（agent-ready 站點的受控實驗）方向一致，這篇是在真實站點和真實 harness 上的觀察性驗證；與 Steiner et al. 2026 的結構化接口優於 HTML 一致（轉引，未複現）；與綜述 2607.14035 對 GEO 技術缺乏穩定因果證據的判斷相呼應（轉引）。
- 與哪些研究的結論矛盾：對 Aggarwal et al. 2024（GEO 頁面編輯）保持距離：作者認為其只在「已被檢索」條件下成立；不直接矛盾。與「站外提及（Reddit/列表文）能增加被推薦」的常見 AEO 建議存在張力，但本文只測了 drill-down 階段。
