# 2611.01126 Do GEO Gains Survive the Live Web? Evaluating In-the-Wild Visibility Gains of Generative Engine Optimization via LIVE-GEO

- 日期：2026-10（arXiv v1，2026-10-31）
- 發表狀態：預印本（未註明）
- 作者類型：學術為主（密西根大學、伊利諾大學香檳分校、Starc Institute）。**利益關係需點明**：論文中表現最好的方法 CORE，其原論文作者中有三位（Haibo Jin、Huimin Zeng、Haohan Wang）同時是本文作者；評測用的排序提示詞改編自 CORE 論文；LIVE-GEO 網站以「一家新創合作方的公開產品網站」名義運行（第 1 節）。
- 一句話總結：把 5 種 GEO 改寫後的虛構產品頁發布到真實網站，再把網址交給 ChatGPT、Gemini、Grok 讀頁排序；整體「誰最強」（CORE）大致能從直接給文字的 API 評測延續到真實 AI 搜尋，但個別品牌層面的結果在引擎之間、評測方式之間、候選順序之間都很不穩定；「加統計數據」改寫 80 篇全部含規格不支持的數字。

## 研究問題

四個研究問題（第 1、4 節）：

- RQ1：同一批 GEO 改寫，在不同 AI 搜尋（GE）與「直接給文字」的模型評測之間，可見度是否一致？
- RQ2：可見度對重複評測、候選順序、公開身分（產品名稱是否帶策略標籤）有多敏感？
- RQ3：極小的價格差（±0.2%）與網址進入方式（給品牌頁 vs 給 6 個產品頁）如何影響可見度？
- RQ4：數字忠實度標記可靠嗎？套用標記（把被標記產品排到後面）後可見度怎麼變？

核心問題寫在標題：在受控條件下量到的 GEO 增益，到了真實網頁、由商業 AI 搜尋自己去讀時，還在不在。

## 研究設計

- 系統類型：**商業引擎但手動提供 URL**。三個 GE 透過網頁介面使用，會自己打開並讀取真實上線的頁面；但候選集合由研究者以 6 個產品網址（或 1 個品牌頁網址）直接給定，**沒有測試開放檢索**（引擎是否會自己搜到這些頁面）。另有 5 個「直接給文字」的評測器（無聯網），屬固定上下文。
- 涉及的引擎和模型，以及測試日期：
  - GE（網頁介面）：ChatGPT（GPT-6）、Gemini（3.6 Thinking）、Grok（Expert 模式）。
  - 直接給文字的 API：GPT-4o、DeepSeek-V4-Pro、Kimi K2.6、Claude Sonnet 5.5；本地模型 Qwen2.5-3B-Instruct（第 4.1 節）。
  - 改寫用模型：四個非 CORE 策略用 GPT-4.1；CORE 用 GPT-3.5 Turbo 寫初始後綴、GPT-4o 排序並優化後續後綴，**最後一輪還把 ChatGPT 對 CORE 未勝出產品的實際排序回饋給優化器**（第 4.1 節）。
  - 測試日期：論文只說每次請求都記錄抓取時間，**未報告具體測試日期**。
- 樣本：80 個虛構品牌，分屬 18 個產品族群的 80 個冷門品類（附錄 A 表 7）；每品牌 6 個產品（1 個 Original ＋ 5 個改寫），規格相同，只有描述、7 則評論與 ±0.2% 內的價格不同。查詢固定為 `best {category}` 一種模板。主條件每個 GE 各跑一次 80 個品牌；ChatGPT 等價條件另有一次完整重跑。Claude API 拒答 2 個品牌，n=78。
- 五種策略：Statistics Addition（加統計數據，2023 年 GEO 原論文的技巧）、C-SEO（C-SEO Bench 的 Content Improvement）、E-GEO（迭代優化改寫提示詞）、AgenticGEO（代理式自我演化策略搜索）、CORE（依排名回饋優化附加後綴的方法）。
- 對照設計：
  - 同品牌內 6 個產品互為對照（規格相同），Original 為模板生成的平淡原稿。
  - 條件操弄：網址入口（產品頁 vs 品牌頁）、候選順序（每品牌隨機一次後固定；另有兩個相反的固定順序）、身分遮蔽（把產品名中的策略標籤換成中性代號，附錄 C）、價格（等價 vs ±0.2%）。
  - 配對比較用 10,000 次品牌層級 bootstrap 的 95% 區間，未做多重比較校正（表 2 註）。
- 評估方式：客觀指標——Top-1 率、平均名次、品牌內 Spearman ρ、同一第一名／最後一名的品牌比例、平均名次絕對差。數字忠實度由 JEV 模型判定，並以 194 個公開資料集案例（表 5）與 3 位人工審閱者、50 篇描述（表 6）驗證。
- 證據等級：**C**（商業 AI 搜尋真實讀頁，但網址手動提供、跳過檢索；有一次重跑與多個條件，但每條件多為單次）。直接給文字評測器的部分為 E。

## 主要發現（逐條列出，附數字和出處節號）

1. **整體領先者能延續到真實 AI 搜尋。** ±0.2% 價格、給產品網址時，CORE 在 8 個評測器中的 7 個拿下最高 Top-1 率；在三個 GE 上分別為 76.3%（ChatGPT）、67.5%（Grok）、66.3%（Gemini），平均名次 1.74、2.21、2.01，領先第二名 56–66 個百分點（第 4.2 節 RQ1、表 1）。（筆記者註：6 選 1 的隨機基準為 16.7%。）
2. **品牌層級極不一致。** 三個 GE 兩兩之間，只有 48.8%–66.3% 的品牌選出相同第一名，品牌內平均 ρ 只有 0.32–0.48（表 3）。直接給文字的評測器與 GE 的一致度從 DeepSeek 的 ρ=0.50 到 Claude 的 ρ=−0.31 不等；Claude API 把 Original 排第一（44.9%）、CORE 墊底（平均名次 5.56），與三個 GE 全部負相關（ρ −0.31 至 −0.22，相同第一名低於 10%）（第 4.2 節、表 1、表 3、圖 4）。作者結論：「只有整體層面的增益能延續到真實網頁」（第 4.3 節、第 5 節）。
3. **重跑穩定，但呈現方式一變就變。** ChatGPT 同文字、同提示詞、同順序重跑：ρ=0.85，相同第一名 80.0%、相同最後一名 90.0%，CORE Top-1 82.5% vs 83.8%（表 1、表 3）。只把 6 個網址順序倒過來，CORE 在 ChatGPT 的 Top-1 從 73.8% 變 93.8%（差 20 個百分點），平均名次改善 0.79 [−1.19, −0.41]；兩個相反順序之間相同第一名 75.0%、ρ=0.74（表 1–3）。Grok 上兩順序 CORE 為 37.5% vs 50.0%；Gemini 上第一名在 E-GEO（30.0%）與 CORE（28.8%）之間換手（第 4.2 節 RQ2）。直接給文字的 API 也有順序敏感：倒序後 ρ 為 DeepSeek 0.33–0.37、Kimi 0.39–0.49、Claude 0.76–0.85，相同第一名 43.6%–72.5%（表 4）。
4. **產品名中的策略標籤本身會影響排序。** 遮蔽身分後，CORE 在 ChatGPT 的 Top-1 從 83.8% 降到 76.3%，Statistics Addition 從 12.5% 升到 21.3%，平均名次改善 0.60 [−0.91, −0.29]（表 1、表 2）。
5. **價格與網址入口改變數值，但不改變 Top-1 領先者。** 等價 vs ±0.2% 價格，CORE Top-1 最大差 16.2 個百分點（Gemini 82.5% vs 66.3%）；ChatGPT 上 Original 平均名次改善 0.59 [−0.84, −0.38]，Gemini 上 CORE 變差 0.63 [0.21, 1.06]（表 1、表 2）。給品牌頁 vs 給產品頁，ChatGPT 的 CORE Top-1 為 46.3% vs 76.3%（差 30.0 個百分點）；ChatGPT 等價、品牌頁條件下，平均名次最佳的是 E-GEO（2.28）而不是 CORE（2.69）（第 4.2 節 RQ3、表 1）。
6. **「加統計數據」80 篇全部含規格不支持的數字，AI 搜尋並未因此懲罰它。** JEV 標記 400 篇改寫描述中的 86 篇：Statistics Addition 80/80、AgenticGEO 3、E-GEO 2、CORE 1、C-SEO 0。原因是該提示詞要求「有說服力的統計」並允許假設性數據，例如「保溫提升 18%」；CORE 與 AgenticGEO 被標記的描述也含「節能 30%」「最多省水 60%」這類無依據比較（第 4.2 節 RQ4、表 1）。即使如此，Statistics Addition 在 ChatGPT（±0.2%）仍有 10.0% 品牌拿第一、平均名次 3.18，明顯優於平淡原稿的 5.28（表 1）。
7. **數字忠實度標記可靠。** JEV 在 194 個數字核查案例上與參考標籤一致 90.72%（表 5）；與三位人工審閱者的二對一多數在 50 篇中全部一致，49 篇三人一致，Fleiss' κ=0.96，十個多數標記全屬 Statistics Addition（表 6；另有第四位審閱者被事後排除，納入則 κ=0.53，多數結果不變）。研究者事後把被標記產品排到後面，Statistics Addition 在所有條件下 Top-1 歸零、平均名次 5.95–5.96；ChatGPT 上 CORE 從 82.5% 升到 86.3%（表 1）。注意：這是研究者的事後重排，**不是引擎行為**。
8. **所有改寫在 GE 上幾乎都勝過平淡原稿。** ChatGPT（±0.2%）Original 平均名次 5.28、Top-1 2.5%；Grok 5.84、0.0%；Gemini 4.88、10.0%（表 1）。唯一例外是 Claude API。

## 對應原理和管線階段

- 原理編號：
  - [4] 進入上下文後的相關性與位置：在真實 AI 搜尋讀取 6 個給定頁面的情境下，候選順序對第一名影響可達 20 個百分點。
  - [5] 可抽取的證據：整頁以數字充實的改寫勝過平淡模板，但數字可能是虛構的。
  - [6] 吸收與保真：引擎沒有懲罰規格不支持的數字。
  - [7] 可見度是隨機分佈、如何測量：重跑 ρ=0.85；引擎間、評測方式間、順序間的不一致；直接給文字的 API 不能當作真實 AI 搜尋的代理。
  - [9] 優化與操縱同一通道：最強的 CORE 是以排名回饋優化附加後綴的方法，並曾用 ChatGPT 的實際排序作回饋。
- 管線階段：重排/上下文 → 生成（排序、推薦）；吸收/保真（數字忠實度）。觸發、抓取/索引、檢索均未測試。
- 新原理候選：「評測代理不可轉移」——用直接給文字的模型 API 測得的 GEO 效果，與真實 AI 搜尋讀頁後的結果，品牌層級相關可以為負；評測器本身就是一個需要驗證的變數。另一個較小的候選：頁面上可見的身分標籤（產品名）本身會影響排序。

## 對實踐的含義

- 有實驗支持的做法：
  - 在自己關心的那個 AI 搜尋上、用真實上線的頁面測量，而不是用 API 直接餵文字代替（RQ1）。
  - 每次測量都記錄候選順序、網址入口、價格與頁面版本，並做順序輪換或隨機化（RQ2、RQ3）。
  - 把任何改寫與「平淡原稿」比較時要知道：幾乎任何改寫都勝過模板原稿，這不等於勝過真實競爭者。
- 作者建議但未經驗證的做法：
  - 以 LIVE-GEO 作為公開、Kaggle 式的長期基準，讓使用者自報結果；作者認為凍結快照可讓不同使用者的數字可比（第 4.3 節）。未報告任何外部使用者的數據。
  - 用數字忠實度標記阻止「以虛構數字換排名」的投稿（第 4.3 節）。這是平台規則，不是引擎機制。
- 被證明無效或有害的做法：
  - 「加統計數據」的提示詞（允許假設性數據）會系統性地產生虛構數字：80/80 被標記（RQ4）。它在引擎上的排名優勢只來自與平淡原稿比較，並落後於其他整頁改寫方法。
  - 用 Claude API 等直接給文字的評測器挑選 GEO 策略：其排序與三個 GE 負相關。

## 局限與效度威脅

1. **沒有測檢索。** 網址由研究者直接給出，引擎只需讀頁排序；標題中的「Live Web」指頁面真實上線，不是引擎自己找到它們。屬 C 級。
2. **利益關係。** 三位作者是 CORE 的作者；CORE 在最後一輪用 ChatGPT 的實際排序做回饋，其他四種策略沒有；評測提示詞改編自 CORE 論文。CORE 在 ChatGPT 上的優勢可能部分來自「對著被測引擎調過」。
3. **身分標籤洩漏。** 非遮蔽條件下產品名直接帶策略名（如「Brand CORE」「Statistics Addition」）；遮蔽後 CORE 降 7.5 個百分點、Statistics Addition 升 8.8 個百分點。主表大多是未遮蔽結果。
4. **基準太弱。** Original 是模板生成的平淡文字，所有改寫都只需勝過它與彼此；不代表真實市場中有競爭力的頁面。
5. **固定順序結果與隨機順序不一致，且作者未解釋。** 作者以 ChatGPT 隨機順序（82.5%）落在兩個固定順序（73.8%、93.8%）之間為由採用隨機化；但在 Gemini 上，CORE 隨機順序（等價）82.5%，兩個固定順序卻只有 23.8% 與 28.8%；Grok 為 65.0% vs 37.5%、50.0%（表 1）。隨機順序的值落在兩個固定順序之外，暗示可能有未記錄的時間或其他差異（筆記者觀察）。
6. **樣本與情境狹窄。** 80 個冷門虛構品類、單一查詢模板 `best {category}`、6 個候選、使用者自訂排序提示詞（要求打開每頁並回傳 JSON），與一般使用者的自然提問不同。主條件多為單次執行；只有 ChatGPT 等價條件有一次重跑。
7. **未報告測試日期**，模型版本只以介面名稱記錄。
8. **多重比較未校正**（表 2 註），單一區間排除零的結果應保守看待。
9. **忠實度只看數字、只看描述**，評論與非數字主張不在範圍內；人工驗證只有 50 篇，且第四位審閱者被事後排除。

## 與其他研究的關係

- 支持哪些研究的結論：
  - SAGEO Arena 類的研究（生成階段的增益可能在上游流失）與教材「固定候選實驗高估效果」的方向：本文顯示直接給文字的評測與真實 AI 搜尋在品牌層級的一致度最高只有 ρ=0.50，最低為負。
  - 「單次測量不可信」：ChatGPT 重跑約 20% 品牌第一名改變。
  - 「可見度導向的改寫會降低忠實度」：允許假設性數據的改寫 100% 產生無依據數字。
- 與哪些研究的結論矛盾：
  - 與教材「位置效應在真實系統中弱得多」（購物 agent 模擬、受控重放）部分矛盾：在商業 AI 搜尋讀取 6 個給定頁面的設定中，順序讓第一名比例擺動 20 個百分點、四分之一品牌的第一名改變。
  - 與「加統計數據在新模型上無效或有害」的重測不直接矛盾，但呈現另一面：以整頁改寫方式加入數字（雖為虛構），在三個 GE 上平均名次仍明顯優於平淡原稿；只是落後於其他整頁改寫方法。兩者衡量指標（引用份額 vs 產品排序）、基準（真實競爭文件 vs 模板原稿）與實現方式（附加區塊 vs 整頁改寫）都不同。

## 值得到從業者社群（Reddit）驗證的問題

1. 在自己的產品比較頁或清單頁上，只改變候選順序（不改內容），AI 搜尋的推薦第一名會改變多少？
2. 頁面上含有規格不支持的數字（如「節能 30%」）時，AI 搜尋是否照單全收、轉述給使用者？有沒有引擎會因此降權？
3. 用 API 直接餵文字做的「GEO 評分工具」，其結果與真實 AI 搜尋讀頁後的排序一致嗎？
4. 產品名或頁面上的標籤用詞（例如帶「Pro」「Original」）是否會影響 AI 推薦順序？
5. 給品牌總頁 vs 給單一產品頁，AI 搜尋的推薦結果差多少？

## 與教材的關係
